Rapp network status icons (14 pt pixel sprites, 2026-11-17)

strong = cheetah leaping; ok = rabbit hopping (was normal); weak = tortoise; down = cracked egg (was offline).
Each base PNG: 14 x 14 pixels; 2.0x/: 28 x 28; 3.0x/: 42 x 42, exact nearest-neighbour multiples.
Colours: only #000000, #FFFFFF, #909090 on transparent. Draw in the original colours, never as a
template (tinting would flatten the white and gray detail); FilterQuality.none, no smoothing.
Imported from rapp-pixel-icons-14pt.zip (png/), renamed to match NetLevel. The zip's SVGs,
Xcode .imageset folders, pixel maps and preview are not used: this app is Flutter.
