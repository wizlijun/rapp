# Linux 0.15.26：快捷区按键重排、折叠键与 Omarchy 锁屏输入对齐

基线 `origin/main` `58681d3f`（macOS 0.15.25）及本地 Linux 锁屏提交 `0853fa0d`。用户要求对齐 macOS 变更、实现 Linux、发布 Linux 版并安装到本机。

## 对齐结果

- **快捷区按键重排与末尾 `⋯ ⌄`**：共享 Dart 实现（`key_bar_keys.dart` / `key_bar.dart`）已带入第一排 11 颗 `Tab ⇧Tab Esc ⌃C ⌃ ↑ ↓ ⌫ ⏎ ⋯ ⌄` 与第二排 `⌘C ⌘V ⌥ (⌘) ← → ⌃O ⌃R ⌃T ⌃B ⌃L`（新增 `⌃L`，移除 `⌃D`，`⌘C`/`⌘V` 读屏保留「复制」「粘贴」）。
- **Linux 鼠标焦点与输入法修复**：将 `KeyBar` 包裹在 `TextFieldTapRegion` 中，使 Linux 桌面用鼠标点击 `⌄`、`⋯` 或按键栏任意键时不再触发 `TextField` 失焦，保持写作框焦点、选区与未提交 IME 组合输入，与 `QuickToggle` 和 macOS `NativeEditor` 行为一致。
- **Linux 回归覆盖**：新增 Linux 断言覆盖第一/二排键序与语义、终端/应用会话 `⌃L` 与 `⌫`/`⌃⌫`、`⌄` 按会话类型收起、收起时释放粘滞 `⌃` 避免远端修饰键粘连，以及鼠标点击 `⋯`/`⌄` 保持选区与 IME composing；在 `rapp-host-linux` 补充 `evdev(37)`（L）、`evdev(48)`（Tab）、`evdev(51)`（Backspace）键码映射断言。
- **macOS `previous/rapp.app` 开机防启动修复（`ef513707`）**：仅适用于 macOS `.app` 自更新与 Launch Services。Linux 通过 pacman 就地升级或替换便携包，且 `rapp-service` 仅在 `.app` 包内启用 `UpdateOpts`，开机仅由单个 systemd 用户服务拉起，不存在同类旧版重起问题；Rust `rapp-update` 与 `rapp-testkit --test update` 全部在 Linux 通过。
- **Omarchy Quickshell 锁屏输入（`0853fa0d`）**：随本次 0.15.26 一并发布，并同步更新打包说明 `README-LINUX.txt`。
- 发布号 `0.15.26`（Flutter `0.15.26+82`），协议保持 `v15`；仅发布 Linux（`--latest=false`），保留 macOS Latest 自动更新入口（`v0.15.25`）。
