## 1. 差异审计

审查 `34d9e9c2..62b96219` 的 Linux 侧行为：

1. **本机页「中心服务」连接状态区块（`14a063d3`：`fix/ios-center-section`）**：
   - `gui/lib/ui/main_window.dart` 在无本机服务的 `_iosLocal()` 分支补入 `if (state.stateSync != null) StateSection(sync: state.stateSync!)`，使 iOS/iPadOS 的「本机」与桌面端的 `_local()` 一致。
   - Linux 桌面端具有本机服务（`caps.hasService == true` 且传入 `ServiceMonitor`），走 `_local()` 分支（第 223–262 行），在「设备 → 本机」页同时展示 `StateServiceRow`（控制本机 `rapp-center` 启停）与 `StateSection`（自动 / 关 / 手填地址及「已连上 / 没找到中心服务 / 连不上」连接状态）。
   - 在 `gui/test/ui/main_window_test.dart` 补充 `TargetPlatform.linux` 用例，锁定 Linux 桌面端打开「设备 → 本机」时同时呈现 `LocalSection`、`StateServiceRow` 与 `StateSection`（显示「中心服务」连接状态）。
2. **版本与打包结构**：
   - Rust 工作区全部 20 个 crate 与 `gui/pubspec.yaml` 已由上游同步为 `0.15.61`（协议仍为 v16，便携包与 `rapp-omarchy` `/opt/rapp/` 保持 42 个文件与 15 个 ELF 二进制）。
   - 更新 `scripts/package-linux.sh` 内置 `README-LINUX.txt` 版本兼容说明至 `0.15.61`。
