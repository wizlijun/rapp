## 1. 差异审计与 Linux 侧更新

审查 `70de5cf7..ce751dba` 的 Linux 侧行为：

1. **`rapp-center` 新增内置能力 `prefs` 与 Linux 发布包冒烟测试（`services/center` + `scripts/test-linux-bundle.py`）**：
   - `rapp-center` 的 `GET /v1/routes` 新增内置路由 `{"name":"prefs","kind":"builtin","v":1}`（与 `state` 并列），提供 `/prefs/v1/all`、`GET/PUT /prefs/v1/<phrases|keys|layout|stars>`（CAS `409`）、`PUT /prefs/v1/usage/<device>` 及 `/v1/watch` SSE `prefs.*` 推送，并在约 1 秒后以 `0600` 权限落盘至 `local/center/prefs.json`。
   - 更新 `scripts/test-linux-bundle.py`：对齐 `GET /v1/routes` 的 `state` + `prefs` 双路由断言，并在隔离网络命名空间中实测真实打包 `rapp-center` 的 `GET /prefs/v1/all`、`PUT/GET /prefs/v1/stars`、过期 `base` 的 `409` 冲突返回以及 `local/center/prefs.json` `0600` 权限落盘。
2. **快捷区第一行重做、可编辑键盘布局、侧栏「按键」页与输入块抓手加长（`feat/quick-row`）**：
   - `gui/lib/main.dart` 在 Linux 与 macOS 桌面端统一加载 `QuickPrefs.load(data.prefsDir(), legacy: prefs.phrases)` 并创建 `QuickSync` 接入 `StateSync`，无中心服务或旧中心服务时自动降级为本机存储（设置页显示「只存在本机」）。
   - 默认快捷键盘第一行精简为 `Tab Esc ⌃C ⌫ ⏎ ↑ ⋯`（`⇧Tab` 移入常用语菜单的「切模式」AI 命令）；第一行末尾固定 `按键▾` 与 `常用语▾` 两个菜单；整块 `KeyBar`（含 `PhraseStrip`）继续包裹在 `TextFieldTapRegion` 内，保证 Linux 鼠标点击快捷区芯片不抢走输入框焦点与 Fcitx5/IBus 预编辑。
   - 在 `gui/test/quick/quick_row_widget_test.dart` 补充 `TargetPlatform.linux` 桌面端用例，验证在输入面板展开时用鼠标点击第一行按键动作芯片（`keyact-clear` `⌃L`）可正常向终端发送 `Ctrl-L`，同时保持输入框焦点、选区与 IME 未上屏预编辑不变。
3. **总览本机列「连上的服务」重连重查与折行（`fix/center-host-reask`）及文档更新**：
   - `LocalServices` 在中心服务重连后重新调用 `ServiceMonitor.stateHost()` 查询所在设备，且状态文案一行放不下时自动折行显示完整内容。
   - 同步更新 `scripts/package-linux.sh` 内置 `README-LINUX.txt` 至 `0.15.63`。
