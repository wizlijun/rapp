# Linux 0.15.44 对齐计划（对应 macOS 0.15.43）

日期：2026-11-26

## 1. 上游变更审计（`7e19d329..2586de48`，macOS `v0.15.43`）

1. **会话标注（`feat/session-labels`）**
   - `rust/service/src/labels.rs`、`rust/service/src/peer.rs`、`rust/service/src/ipc.rs`、`rust/service/src/term.rs`：
     - 被控端在 `local/labels.json`（`0600` 权限原子写，异常文件自动备份为 `labels.json.bad`）持久化每个会话的自定义 `title`（≤64 字）与 `note`（≤200 字，换行折为空格），容量上限 500 条，且标题/备注内容绝不写入日志；
     - 新增加法协议操作 `watch_labels`、`set_label`、`reset_label` 及本机 IPC `labels` / `set_label` / `reset_label`；`open_term` 新增可选 `label_from`，在已停止终端重新启动时原子迁移标注。
   - `rust/hub/src/labels.rs`、`gui/lib/labels.dart`、`gui/lib/ui/session_block.dart`、`gui/lib/ui/inbound.dart`、`gui/lib/ui/main_state.dart`、`gui/lib/ui/open_apps_menu.dart`：
     - 总览、顶栏切换列表、侧栏「会话」页与本机列统一使用 `SessionCard` 展示标题与备注（带备注高 72px，无备注 56px；右键/长按弹出「改标题和备注…」与一键「还原」）；
     - 自定义标题替代文字终端首行后，第二行自动保留前台程序名（如 `claude · 等确认 · …`）；
     - 未打开但有标注的会话常驻于分组末尾（运行中显示「没有打开 · 打开」，已退出终端显示「CLI · 已停止 · 启动」并调用宿主机首个可用终端启动器如 Linux `ghostty` 带 `label_from` 拉起）；本机列下方同时展示「有标注的会话 · N」。
2. **总览设备系统标志改用官方图形（`fix/os-marks-redraw`）**
   - `gui/lib/ui/os_mark.dart`、`gui/lib/ui/os_mark_paths.dart`、`gui/lib/ui/svg_path.dart`：
     - 采用各系统官方 24×24 SVG 路径（含 `omarchy.org` MIT 官方标志与 Linux Tux 实心标志），启动构建一次路径缓存避免重绘开销。
3. **协议与兼容性**
   - 桌面流协议保持 **v16**（与 macOS `0.15.35–0.15.43` 互通）；会话标注新 Op 为向后兼容加法（旧版被控端返回 `unknown op` 时客户端自动隐藏标注菜单）。
