# Linux 0.15.34：程序状态 S1、状态队列、需要你直达、终端标题与常用终端恢复对齐

基线 `origin/main` `0fc39f3b`（macOS 0.15.29–0.15.33）。用户要求对齐 Linux 版并发布 Linux / Omarchy 补充版本。

## 对齐结果

- **程序状态 S1（OSC 7501，macOS 0.15.29）**：`rapp-term` 扫描器、解析器、记录表、探测优先应答（`pump_output` 先写入 `shared.input` 再转发窗口）、`term.json` 的 `programStatus` 开关与未读规则均为跨平台 Rust 实现，Linux 被控端与客户端直接共享；`rapp-term` 在 Linux 瞬态 systemd 用户服务下正常持有伪终端并随状态与列表上报 `ps`。
- **状态队列、需要你直达与总览程序状态（macOS 0.15.30）**：共享 Dart 实现（`term_status.dart`、`hint_history.dart`、`needs_you.dart`、`overview.dart`、`main_state.dart`），Linux 桌面端复用顶栏提示右侧 `▾` 统一状态队列、「需要你」全量可滚列表与整行点击直达、总览五态展示及设备离线自动清除等待灯。
- **终端程序标题（OSC 0/1/2）、重名 `· 2` 后缀与总览「常用 · 终端」恢复/新建（macOS 0.15.31–0.15.33）**：`rust/term/src/pty/title.rs` 与 `serve.rs` 为跨平台 Rust 实现，Linux 被控端优先采用 OSC 1 标签名、清除开头旋转符号并按进程号顺序为同设备重名标题追加 ` · 2` / ` · 3`；`inline_edit.dart` 未改名不冻结动态标题；总览「常用 · 终端」重启后首次点击显示「打开」以恢复在跑文字终端，随后显示「新建」每次点击新建终端。
- **Linux 宿主启动首点等列表修正**：修正 `gui/lib/ui/main_state.dart` 的 `_termListMissing`，使无应用级画面共享的 Linux 宿主（`graphical: false` 或 `applications: false`，强制走文字终端）即使此前存过 `pixels` 偏好，在启动后终端列表尚未到达时点击「常用 · 终端」也会先等待 `terms` 列表再决定恢复或新建，不再跳过等待。
- **Linux 回归补充**：在 `gui/test/ui/overview_test.dart` 与 `gui/test/ui/top_bar_test.dart` 新增 `TargetPlatform.linux` 回归用例，覆盖 Linux 桌面上的程序状态、重名终端标题 `~/git/rapp · 2`、状态队列 `▾` 与「需要你」点击直达、仅桌面 Linux 宿主（`applications: false`）下总览「常用 · 终端」等待列表并恢复运行中终端及切换「新建」调用 Linux 启动器（`ghostty`/`foot`）的行为。
- 同步更新 `scripts/package-linux.sh` 内 `README-LINUX.txt` 说明，版本号升至 `0.15.34`（Flutter `0.15.34+90`），协议保持 `v15`；仅发布 Linux（`--latest=false`），保留 macOS Latest 自动更新入口（`v0.15.33`）。
