# Linux 0.13.0 对齐

基线 `db759c4`（0.13.0），比较上一 Linux 发布源码 `1923dca`。在独立 worktree 实现，保留主工作目录及用户正在运行的服务。

## 变更与实现范围

| 0.13.0 变更 | Linux 现状与工作 |
| --- | --- |
| 协议 v13：遮挡、关闭遮挡、新应用、密码焦点 | core/worker已有协议；补原生窗口状态、可用操作和密码焦点键路由，验证真实帧消息链 |
| 本地密码框不启用中文组字 | Flutter输入类型需明确 visiblePassword，使GTK IMContext获得PASSWORD purpose；候选桥接按焦点释放，不切换其他应用的输入法 |
| 粘贴块位于光标并按正文顺序发送 | Flutter已有行内块；补Linux拆分窗口共享草稿的mark/anchor交接，覆盖删除、恢复、发送和往返拆窗 |
| 系统正文字号、半透明写作面板、主题焦点框、网络图标 | Flutter共享代码已有；补GTK原生路径的字号/颜色，验证缩放与候选字形不省略 |
| 全局分享号、协议识别、地址格式、冲突处理 | 服务/CLI共享Rust代码已有；跑Linux隔离服务、端口转发、冲突与迁移回归，修实际平台或脚本缺口 |
| 打包/版本升级 | 升级隔离测试的协议断言，修自定义Cargo构建目录取worker路径，构建0.13.0 Omarchy完整包 |

并行边界：GTK4与worker测试；GTK3/native桥接与独立显示验证；后端/CLI/构建脚本；主代理负责Dart跨界接口、集成、审查和验证。

## 约束与验证

- Linux已有客户端、文本终端宿主和端口共享范围内对齐；0.13.0的macOS图形宿主采集/AX功能不凭空映射为尚不存在的Linux图形宿主。
- 候选、输入法、窗口测试使用私有D-Bus、临时配置和隔离显示，不向用户桌面注入按键，不读取或记录实际密码。
- 密码焦点期间不自动拉起写作面板，直接键路由仍可输入；记录逻辑覆盖发送时与完成时焦点变化，防止异步完成漏记状态。
- 分享监听仍为TCP回环地址；服务QUIC UDP端口沿用现有配置，不新增LAN端口规则。
- 先逐组件有意义的回归，再完整Linux构建/打包。实际macOS 0.13.0对端和用户Wayland桌面的交互验收单独记录，不能用mock通过代替。

## 已完成验证

- Flutter 全量：1848 通过、3 项跳过（平台限定/显式性能开关）；静态分析无问题。真实 v13 worker 连续处理遮挡、新应用、密码焦点和后续帧，验证 native 通道及交接中的迟到插入。
- 候选中文字形：真实 Noto CJK 字体下 3 主题、2 缩放、3 宽度共 18 项通过，检查实际渲染图；候选文字不再变成省略号。
- 后端：505 项单元/集成测试通过，包含全局分享号、IPv4/IPv6 回环、协议识别、冲突、转发、迁移和原阈值 one-RTT 检查。
- GTK4：8 项单元、私有 D-Bus/Broadway 候选交互与密码焦点测试、7 场景 v13 fixture；Clippy 通过（保留仓库既有 chunks_exact_to_as_chunks 例外）。
- GTK3：真实方法入口覆盖 mark/anchor 光标插入、跨视图共享、删除、顺序发送、IME commit 后 FIFO 发送/交接、关闭时立即销毁、提示 epoch、主题字号和本地密码上下文；私有 D-Bus 候选 12 组、实际 GTK 显示 4 组通过。
- 构建脚本：默认、相对、自定义含空格 Cargo target 路径与启动器参数保真测试通过。发布包另以实际 release workers 跑隔离 bundle smoke，并校验归档和安装包摘要。

实际 macOS 0.13.0 对端与用户 Wayland/Fcitx 硬件输入尚待设备验收；以上自动化未操作用户桌面、密码、已安装服务或防火墙。Linux 图形宿主仍不在现有功能范围。0.13 分享配置带新增字段，旧 0.12.2 读取这些配置不兼容，不能承诺直接降级完整恢复分享表。

## 发布号同步

发布前远端 main 新增 `bb83df3`，仅将 Cargo/pubspec 发布号从 0.13.0 更新为 0.13.1，功能代码未变化；原 0.13.0 tag 未发布二进制。Linux 适配合入该版本提交，正式安装包与便携包使用 **0.13.1**，上传既有 macOS 0.13.1 Release。0.13.0 本地验证产物保留，但不另建该版本的公开 Release。
