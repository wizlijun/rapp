# Linux 0.15.22：输入块、快捷区与本机语音纠词对齐

基线 main `6ed46043`（macOS 0.15.21）。用户要求补齐 Linux，完成后发布 Linux 版。

## 对齐范围

- 浮动输入块、写作框内快捷区开关、按会话类型保存显隐、语音气泡覆盖层和 L1 本机纠词继续使用共享 Dart 实现。扩展同一组测试到 Linux，覆盖布局、草稿、语音快捷键、纠词后发送/编辑、密码字段不保留学习来源及 AI 整理。
- Linux 语音语言改为首选列表中中文优先；支持 GTK locale 列表和 GNU `LANGUAGE` 列表。没有中文时使用第一项，只传 Whisper 所需的语言码；C/POSIX 回退英语。
- LinuxSpeechChannel 使用单调时钟，在 final 之前发出同一份 timing 契约：开始调用到首个非空 partial、stop 到 final。每轮重置；自动结束无 stop 耗时；取消的旧事件不会传入下一轮。重复/晚到 stop 不再创建无效超时。
- Linux 仍使用本地 Whisper CPU 后端。Apple 的 DictationTranscriber 切换及 NSTextView 像素取整修复属于平台专属实现；Linux 使用 Flutter 编辑器与系统输入法。跨平台交互对齐不代表识别精度与耗时相同。
- 发布版本 0.15.22（Flutter 0.15.22+78），协议保持 v15；仅发布 Linux，保留 macOS Latest 更新入口。
