## 1. 差异审计

审查 `7681dea4..8bc138d0`（`feat/strip-commands`，30 个文件）的 Linux 兼容性：

1. **Linux 前台工具识别（`strip_tools.dart` + `rust/term/src/pty/fg.rs`）**：
   - `fg.rs` 在 Linux 下读取 `/proc/<pid>/cmdline` 首项基名（回退至 `/proc/<pid>/comm`）并计算 `shell = (pgrp == child_pid)`。
   - 核查本机 Omarchy（`mise` 环境）实装工具：`claude`、`codex`、`agy` 的进程 `argv[0]` 基名分别为 `claude`、`codex`、`agy`，与 `agentTools` 的 `progs` 完全一致；`gemini`、`opencode` 等 Node 运行时下支持通过 OSC 7501 `ps.app`（配合 `_jsRuntimes`）识别；退回 `bash`/`zsh`（`shell == true`）时命令按钮立即隐藏，不会向普通 shell 误发斜杠命令。
2. **Linux PC 按键区焦点保持与按键发送（`KeyBar` + `PhraseStrip` + `ComposerPlus`）**：
   - `PhraseStrip` 位于 `KeyBar` 的 `TextFieldTapRegion` 内部，鼠标点击命令按钮（「新对话」「换模型」「搜历史」等）不会抢走写作框 `TextField` 的焦点、选区或 IME 组合态。
   - 按键型命令（如「搜历史」`CmdKey('cr')`）经 `TermSessionPort.sendKeys` 发送 `Ctrl-R`，不读写也不清除粘滞修饰键；文字型命令经 `submitText(..., command: true)` 发送括号粘贴与回车，且不写入输入历史。
   - PC 端写作框 `＋` 菜单「编辑常用语…」直接打开统一的 `PhrasesPage`，支持增删改、拖拽混排、按工具切换「文字 / 按键」及「恢复默认」。
3. **测试与打包文档补齐**：
   - 在 `gui/test/embed/phrase_strip_cmds_test.dart` 增加 `TargetPlatform.linux` 桌面端 `KeyBar` 集成回归测试（覆盖 `claude` `/clear` 发送、`Ctrl-R` 发送、`TextField` 焦点与选区保持、`agy` 不支持命令置灰提示，以及退回 `bash` 隐藏命令）。
   - 更新 `scripts/package-linux.sh` 内置 `README-LINUX.txt` 说明至 `0.15.46`。
