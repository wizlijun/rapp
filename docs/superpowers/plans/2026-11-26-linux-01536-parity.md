# Linux 0.15.36：协议 v16 状态规则客户端、总览本机接入列表与多文字终端对齐

基线 `origin/main` `73aba56c`（macOS 0.15.35）。用户要求对齐 Linux 版并发布 Linux / Omarchy 补充版本。

## 对齐结果

- **协议 v16 与 GUI 状态规则（R1–R4、R6）**：`rapp-client-core`、`rapp-session`、`LinuxSessionPort` 与 `rapp-client-gtk` 均已升级至协议 v16；Linux 客户端完整支持向兼容被控端（如 macOS 0.15.35）发送 `stateRules`（type 43）并接收 `appState`（type 44）推断状态、展示规则库/App 配置页/状态队列（标「推断」）与「需要你」高置信度阻塞项；`rapp-host-linux` 严格校验并安全忽略收到的 `stateRules`，保持向后稳定互通。
- **总览本机列「正在被接入」**：`rapp-service` 与共享 Dart 实现（`inbound.dart`、`overview.dart`、`service_client.dart`）在 Linux 本机列显示「正在被接入 · N」（含对方名称、时长、`传文件` 标记与「断开」按钮）；Linux 侧服务自动拉起的 `--cm --background` 本就不创建窗口或 Flutter 引擎（`gui/linux/runner/my_application.cc`）。
- **多文字终端（`Ctrl+Shift+T` / `Ctrl+Shift+W`、「结束终端」、干净退出与宿主窗口标题）**：
  - `rust/term/src/pty/fg.rs` 通过 Linux `/proc/<pid>/cmdline`、`/proc/<pid>/comm` 与 `/proc/<pid>/cwd` 读取前台程序与工作目录；`wintitle.rs` 改写给宿主终端窗口的 OSC 0 为 `<目录> · <程序>[ — <程序标题>]`（不影响 rApp 画面与 OSC 7501）。
  - `launch.rs`、`holder.rs`、`serve.rs` 支持 `open_term` `from` 继承工作目录（`--cwd`）与 shell，支持 `end_term` 彻底结束终端；Linux 终端窗口随进程退出自动关闭，不执行 macOS AppleScript 标签页清扫。
  - Linux 端快捷键采用 `Ctrl+Shift+T`（在旁边新建）与 `Ctrl+Shift+W`（结束终端，前台非 shell 时弹出确认框，长按重复不误触发）。
- **Linux 回归补充**：
  - `gui/test/embed/linux_session_port_test.dart` 新增真实 `rapp-session` 进程的协议 v16 `state_rules`（43）/ `appState`（44）端到端往返回归。
  - `gui/test/term/term_main_test.dart` 补充 `TargetPlatform.linux` 下 `Ctrl+Shift+W` 结束终端、长按防重与运行程序确认弹窗回归（与已有 `Ctrl+Shift+T` Linux 用例配对）。
  - `gui/test/ui/overview_inbound_test.dart` 补充 `TargetPlatform.linux` 下总览本机列「正在被接入 · N」展示与「断开」回归。
- 同步更新 `scripts/package-linux.sh` 内 `README-LINUX.txt`（注明协议 v16 及与 macOS 0.15.35 互通、从 v15 需双端升级），版本号升至 `0.15.36`（Flutter `0.15.36+92`）；仅发布 Linux（`--latest=false`），保留 macOS Latest 自动更新入口（`v0.15.35`）。
