## 1. 差异审计

审查 `4246bc32..319e4846` 的 Linux 侧行为：

1. **快捷区开关不进输入框，展开时常驻右下角按钮列（`70ee866f`：`feat/quick-stay`）**：
   - `gui/lib/embed/composer_panel.dart` 移除输入框内 `＋` 旁的快捷区开关（输入框恢复为 `[＋] [editor] [发送]`，`_keysPerScale = 2 * 40 + 4 * _edge`），在桌面端（macOS 与 Linux）无论输入面板收起还是展开，右下角 `_cornerRow` 始终保持 `[快捷区开关] [输入/收起] [语音]` 固定顺序与位置。
   - `gui/lib/embed/quick_toggle.dart` 对桌面端 `QuickToggleLook.corner`（`Key('quick-toggle-stack')`）包裹 `TextFieldTapRegion` 与 `Listener(onPointerDown: (_) => state.holdForPanel(session))`，在 Linux 鼠标点击切换快捷区时保持编辑器焦点、文本选区及 Fcitx5/IBus 未上屏预编辑（preedit）不变。
   - `gui/test/embed/quick_toggle_test.dart` 与 `gui/test/embed/input_dock_test.dart` 已覆盖无语音场景下的 Linux 焦点/IME 保护与角落对齐；补充带桌面语音（`DesktopVoice`）的 Linux 用例，验证展开/收起输入框及展开/收起快捷区四种组合下 `[快捷区开关] [输入/收起] [语音]` 几何位置恒定且输入框内无 `quick-toggle`。
2. **Windows 版 B 段 `rapp-host-core` 在 Linux x86_64 上的兼容性（`e03a8415`：`feat/windows-host-core`）**：
   - `rust/Cargo.toml` 工作区成员新增第 20 个 crate `host-core`（依赖 `libz-sys` `["static", "stock-zlib"]`、`icu_normalizer`、`serde_json` `float_roundtrip`）。
   - Linux 被控端仍使用 `rust/host-linux`（`scripts/build-linux.sh` 不将 `rapp-host-core` 塞入发布包，包内仍保持 42 个文件与 15 个 ELF 二进制），但工作区门禁在 Linux x86_64 下编译并运行 `rapp-host-core` 全部单测、Swift 样本对拍及 `rapp-testkit` `host_session` / `host_service` 集成测试。
