## 1. 差异审计

审查 `62b96219..a75e7018` 的 Linux 侧行为：

1. **总览本机列「连上的服务」（`LocalServices`）**：
   - `gui/lib/ui/overview.dart` 在本机列展开时渲染 `LocalServices`（传入 `hostApi: monitor ?? state.hub`、`localId: monitor?.status?.id`）：在 Linux 桌面端通过 `ServiceMonitor.stateHost()` 查询中心服务运行设备，若是本机则显示绿灯 `本机 · :<端口>`（如 `本机 · :8102`），若是其它设备则显示 `<设备名> · :<分享号>`；`LLM 网关` 行仅在展开显示期间每 60 秒调用 `LlmApi.probe` 探测并在折叠或离开总览时自动取消定时器。
2. **Linux 桌面端总览本机列无人接入时默认折叠（`_LocalFold`）**：
   - `_LocalFold` 依据 `state.localColumnOpen(inbound: monitor?.status?.sessions.isNotEmpty ?? false)` 控制展开/折叠：Linux 启动后无人接入时默认折为 56px 竖条（显示 Linux / Omarchy 系统标、状态灯与竖排「本机」）；有远端设备接入本机服务时自动展开为 220px 列（同时显示「正在被接入」与「连上的服务」），全部断开后自动折回；用户手动展开或折叠后在本次运行内保持用户选择。
3. **测试与打包说明补齐**：
   - 保留变基后的 `0.15.61` Linux 本机页 `StateSection` 回归测试（`gui/test/ui/main_window_test.dart`）。
   - 在 `gui/test/ui/overview_test.dart` 补充 `TargetPlatform.linux` 用例，覆盖 Linux 桌面端无人接入折起、接入自动展开并显示 `本机 · :8102` 的「中心服务」与「LLM 网关」状态、断开自动折回及手动点击保持。
   - 更新 `scripts/package-linux.sh` 内置 `README-LINUX.txt`（更新本机列折叠描述与「连上的服务」说明，并将兼容版本推进至 `0.15.62`）。
