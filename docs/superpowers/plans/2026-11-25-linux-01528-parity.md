# Linux 0.15.28：总览「打开应用」下拉菜单对齐

基线 `origin/main` `21232184`（macOS 0.15.27）。用户要求对齐 Linux 版并发布补充 Linux / Omarchy 版本。

## 对齐结果

- **总览设备列「打开应用 ▾」下拉菜单**：macOS 0.15.27 新增的 `device_apps.dart`、`open_apps_menu.dart` 及 `overview.dart` 为共享 Dart 实现，Linux 桌面端直接启用同一套桌面交互（行高 32、打开即聚焦筛选框、鼠标悬停显示「打开」、`↑↓`/`Return`/`Esc` 键盘导航、星标切换常用且不关菜单、靠近窗口边缘自适应翻折与限宽）。未发现需要另写 Linux 原生代码的缺口。
- **Linux 回归补充**：在 `gui/test/ui/overview_test.dart` 新增 `TargetPlatform.linux` 回归测试，覆盖桌面行高、窄窗口（340px）边界、鼠标悬停选中、点 ☆ 后按 `Esc` 关闭，以及仅桌面 Linux 宿主（`applications: false`）下只展示「屏幕」「终端」并隐藏包名输入框的行为。
- **解锁提示改进**：macOS 0.15.27 中包含的解锁拒绝原因与超时提示优化已在 Linux `0.15.26`（`0853fa0d`）合入，本次延续保持。
- 同步更新 `scripts/package-linux.sh` 内 `README-LINUX.txt` 说明，版本号升至 `0.15.28`（Flutter `0.15.28+84`），协议保持 `v15`；仅发布 Linux（`--latest=false`），保留 macOS Latest 自动更新入口（`v0.15.27`）。
