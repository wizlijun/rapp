# Linux / macOS 0.13.7 对齐

## 基线与范围

- 上一 Linux 发布版为 0.13.1；本次对齐 macOS/main 的 `c23ee8c`（0.13.7）。
- Cargo 版本为 `0.13.7`，Flutter 为 `0.13.7+35`，应用协议保持 v13。
- 保留本地已提交的 Linux GUI / service 单实例修复 `0edbf3c`。
- 在独立 worktree `rapp-linux-0137` 验证、打包；开始构建时主工作区未提交的输入、编解码和性能改动不在此次包中。构建期间 main 独立新增 `50d03f9`（流式渲染优化），该提交同样不在本次包内；main 中的提交和剩余未提交文件均保留。
- 用户选择仅生成安装包，暂不安装。未上传 Release，未替换已安装的 0.13.1，也未重启用户正在运行的服务。

## 功能对齐

0.13.2–0.13.7 的功能使用同一份 Flutter / Rust 实现，无需另写 Linux 分支：

- 输入记录在密码发送后恢复；关闭会话时读取最新草稿，保留失败发送，避免重复保存召回的记录。
- 设置控件统一字号和行高；顶栏顺序、提示历史、网络图标及流量条同步。
- 项目菜单支持「全部」「自由区」及项目切换，删除最后一个项目后解除筛选。
- 文本终端默认「跟着我的窗口」，同步 fit 参数、窗口尺寸请求及多访问方控制规则；按实际字号绘制缩放后的终端。

Linux 原有内嵌、拆分、独立 GTK 客户端、文本终端及端口共享范围不变。Linux 图形应用和桌面被控端尚未实现。README 的旧版本、协议和功能范围说明已修正。

## 验证

- Flutter 静态分析无问题。全量首轮 1862 项通过，1 项因新 worktree 尚无 release worker 失败，8 项因同一前置条件跳过；其余 3 项为平台或显式性能开关。
- 生成正式 worker 后，重跑 `linux_detach_test.dart`、`linux_session_port_test.dart`、`linux_candidates_test.dart`，45 项全部通过，覆盖上述失败及跳过项；使用本机 Noto Sans CJK 字体。
- Rust workspace：1095 项通过、0 失败、9 项既有显式跳过。另在编译和其他测试结束后单独跑 one-RTT 门槛，1 项通过；channel 串行/并行打开中位数为 54.32 / 55.22 ms，原 75 ms 上限未调整。
- 正式 GTK4 客户端通过 7 组独立 v13 对端场景：画面/增量/菜单、宿主提示和密码焦点、stdin 结束、损坏帧、协议不符、输入拒绝与接管、锁定与往返探测。测试使用私有 D-Bus 和 Broadway 显示。
- GTK3 私有 Broadway 测试通过：原生窗口、嵌套弹窗、共享草稿、裁剪和销毁，以及 v13 焦点、提示、行内块和 IME FIFO。
- service 单实例测试在独立网络命名空间通过并发启动、不同数据目录和崩溃恢复；真实临时 systemd 服务验证终端在 worker 服务停止后继续运行。
- 构建路径和启动器参数测试通过。打包成功，仅有既有 tray 插件 `app_indicator_new` 弃用警告。
- 安装包和便携包中 32 个文件逐一摘要相同；12 个 ELF 的依赖解析通过；GUI 版本、包版本及 `BUILD-INFO.json` 源码提交匹配。
- 便携包解压到含空格路径，在独立用户/网络命名空间运行 bundle smoke，通过版本/协议、服务能力、CLI、回环分享号和监听清理检查。

日志在构建 worktree 的 `.build-logs/`，包括 `flutter-analyze.log`、`flutter-test.log`、`flutter-linux-final.log`、`rust-test.log`、`one-rtt.log`、`gtk-client-fixture.log`、`gtk3-desktop.log`、`single-service.log`、`terminal-service.log`、`package-linux-final.log` 和 `bundle-smoke.log`。
