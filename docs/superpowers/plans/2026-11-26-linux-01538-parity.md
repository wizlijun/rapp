# Linux 0.15.38：新建终端去重防重发与前台程序标题对齐

基线 `origin/main` `5924c225`（macOS 0.15.37）。自主嗅探触发 Linux 对齐并发布 Linux / Omarchy 补充版本。

## 对齐结果

- **新建终端防重开与超时提示（`44c19e73`、`a314852f`、`93e050a4`、`1c6c852d`）**：
  - `rapp-term serve` 在轮到排队 `open` 前若请求方已断开则直接跳过（`ASKER_GONE`），避免积压同时弹出多个窗口。
  - `rapp-hub` 不再重发非幂等的 `open_term` / `end_term`，并将 `open_term` 超时放宽至 45 秒。
  - GUI 对每台设备的「新建」串行互斥（`_newingText`，重复点击提示「正在新建终端，请稍候」），`newTermTimeout` 放宽至 50 秒，并对 macOS 被控端自动化权限阻塞给出明确提示；Linux 启动路径保持 `Launched::Yes` 与既有 5 秒启动保护。
- **终端标题显示前台程序（`522c8068`）**：共享 Dart 实现将文字终端标题改为 `<fg> · <name>`（如 `claude · ~/git/rapp · 2`，未知前台程序时回退 `CLI · <name>`），`CLI` 移至副标题行首（`CLI · …`），在 Linux 被控端通过 `/proc/<pid>` 上报 `fg` 后直接生效。
- **Linux 回归补充**：在 `gui/test/ui/overview_test.dart` 新增 `TargetPlatform.linux` 回归，覆盖前台程序标题 `claude · ~/git/rapp · 2`、`CLI · …` 副标题及「新建」单并发防重开提示。
- 同步更新 `scripts/package-linux.sh` 内 `README-LINUX.txt`，版本号升至 `0.15.38`（Flutter `0.15.38+94`），协议保持 `v16`；仅发布 Linux（`--latest=false`），保留 macOS Latest 自动更新入口（`v0.15.37`）。
