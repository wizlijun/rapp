# Linux 0.15.24：快捷区开关评审修正对齐

基线 main `be75bac0`（macOS 0.15.23）。用户要求补齐 Linux，并在完成后发布 Linux 版。

## 对齐结果

- 上游的 TextFieldTapRegion 已修复 Linux 鼠标点快捷区开关丢光标的问题；缩放时给文字让位、窄窗口 ＋ 菜单限宽/位移、开关淡入与无障碍标签去重也全部在共享 Dart 实现中。本次没有发现需要另写 Linux 原生实现的功能缺口。
- 扩展回归：Linux 选区和 IME composing 在开关开合后保持、继续提交中文不丢字、不误发送；全部缩放档位单行文本不产生多余滚动且保持焦点。
- 窄窗口文字宽度与菜单边界用同一组用例覆盖 iOS/macOS/Linux；开关无障碍与减弱动态效果覆盖 Linux/macOS。
- 桌面主题的 compact density 属于现有设计，保留它。新增跨平台测试初版套用了手机的 40px 最小按钮断言，现改为考虑主题密度，未为测试改变生产布局。
- 上游 macOS 原生文件本次只有注释变化；iPhone 横屏按钮换行是 iOS 行为。Linux 语音/协议/宿主实现保持 0.15.22 的已验证逻辑。
- Linux 发布号 0.15.24（Flutter 0.15.24+80），协议 v15。保留 macOS Latest 自动更新入口。

## 验证与发布

- 变更前相关 377 项 Flutter 测试通过、1 项条件跳过；新增三平台窄窗口断言通过。
- 完整 Flutter 回归、发布构建和包校验正在进行，完成后补记结果。

实际物理输入法、触屏与 macOS 真机对端仍需设备验收。本轮发布不自动安装或重启本机服务。
