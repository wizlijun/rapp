# Linux / macOS 0.15.1 对齐

基线为 main `4aa638e0`，比较上一 Linux 发布源码 `98d14b1`；工作区版本 0.15.1 / Flutter 0.15.1+57，协议 v14。

用户随后要求发版和安装：Linux 发布号为 **0.15.2**（Flutter 0.15.2+58），macOS Latest 保持 0.15.1。Flutter 3.50.0 生成的 lockfile 最低 Flutter 约束更新为 3.44.0；依赖版本未变，使干净 worktree 的打包不再因 SDK 重写 lockfile 而中断。发布与安装结果另记于待办。

## 功能与实现

| macOS 新功能 / 修复 | Linux 路径 |
| --- | --- |
| 托盘按设备分组、已打开会话标记、常用与离线状态 | 共用 `tray_menu.dart`；托盘点选分离会话通过 `raiseIfDetached` 提起原生窗口 |
| 多屏从窗口菜单选择，不再自动打开或分离所有屏幕 | 共用 `WindowMenu` / `MainState`；Linux host 已枚举各显示器，按 `desktop:<id>` 选择 |
| 输入历史在关闭记录时仍可召回，同一设备终端共享历史 | 共用内存历史与 `ComposerModel`；↑/↓保留未发送草稿及修改后的历史条目 |
| 写作面板粘贴文本、图片和文件块 | 补 Linux `PasteTextIntent`：Ctrl+V、Shift+Insert 进入 `ComposerPanel`，避免 TextField 自行粘贴而绕过附件与应用剪贴板；右键菜单共用该路径，即使剪贴板没有文本也提供粘贴 |
| 中文组字不触发历史、发送或窗口快捷键 | 补 GTK 分离窗口 preedit 检查；即使输入法拒绝某个按键，也交回文本组件而不执行应用动作；原有提交后 FIFO 插入/发送流程保留 |
| 半透明舞台控件与语音实时文字修正 | 共用 Flutter 实现；Linux 沿用已实现的本地语音后端 |

macOS Dock 菜单在 Linux 使用系统托盘对应入口；iOS 0.15.0 内置 Rime 属于 iOS 硬件键盘实现，Linux 使用系统输入法与现有候选窗口桥接。

## 回归覆盖

- 粘贴修复前，Linux Ctrl+V、Shift+Insert 的应用处理次数均为 0，新增用例失败；修复后每次为 1。
- 编辑器覆盖右键粘贴无文本剪贴板、附件块、中文组字中粘贴延迟至提交后插入。
- GTK 私有 Broadway 测试覆盖带未发送草稿的 ↑、修改历史后的 ↓、组字期间 ↑/↓/回车/Ctrl+加号/Ctrl+Q，以及原有行内块和 IME FIFO；preedit 修复前应用动作断言失败。
- LinuxSessionPort 覆盖原生 ↑/↓携带最新草稿及原生草稿回写；屏幕选择组件同时按 macOS 和 Linux 平台运行。

## 验证结果与构建

- Flutter 全量 **2506 通过、15 跳过**；原有平台限定、性能开关及待重做的按键行用例保持跳过。静态分析无 error/warning，128 条 SDK 弃用 info，`--no-fatal-infos` 成功。
- GTK3 私有 Broadway 原生窗口测试通过；Linux 构建路径、Flutter 版本拒绝、启动器参数保真夹具通过。
- `scripts/build-linux.sh` 使用 Flutter 3.50.0 构建 GUI 和全部 Rust 组件成功，输出 `gui/build/linux/x64/release/bundle/`。包内 14 个 ELF 依赖全部解析；仅有既有托盘插件 `app_indicator_new` 弃用编译警告。
- 隔离网络、临时运行目录中的 bundle smoke 通过版本/协议、服务能力、CLI、回环分享号和监听清理检查。首轮仅移除 DISPLAY/WAYLAND_DISPLAY，服务从 systemd 用户管理器重新读取桌面环境后尝试当前 Wayland，采集超时；改用私有运行目录和不可连接的用户总线后，通过无图形环境的整包检查。没有将本轮桌面串流标记为已验收。
- 日志位于 `.build-logs/linux-0151-{flutter-test,analyze,native-green,build,build-fixture,launcher,bundle-final}.log`；首次失败的复现日志保留用于核查。

## 范围与验收边界

本轮对齐 0.14.14–0.15.1 的桌面客户端变更。Linux host 继续支持整桌面和逐屏共享；单应用宿主、宿主剪贴板/文件传输、自动输入锁屏密码、GNOME/KDE portal 和 setView 局部采集仍未实现，不将客户端能力误称为宿主能力。

自动化使用临时数据、模拟对端及私有显示，不操作已安装实例；尚未进行真实 macOS 对端、物理 Fcitx/IBus 中文输入及多显示器切换验收。本轮源码与构建验证不等同于发布或安装。
