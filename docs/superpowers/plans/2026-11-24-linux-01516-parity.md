# Linux 0.15.16：语音纠错学习对齐与本机安装

基线 main `833d134e`，包含语音记住改法、按用途整理，以及总览插图点击穿透回归。用户要求补齐 Linux，并打包安装。

## 差异与处理

- 纠错比对、记住/删除词条、按应用选择提示词或对人、偏好保存均由共享 Dart 实现提供。
- LinuxSpeechChannel 之前忽略 start 的 hotwords 参数；补通每次录音的热词快照，传入本地 Whisper initial prompt。共享学习成功后的热词缓存刷新现在可进入 Linux 识别器。
- 限制词条数量、Unicode 长度和上下文字节数，过滤空白及控制字符；保持无词表时的兼容性和静音输出为空的行为。
- 纠错气泡用例同时覆盖 Linux/macOS；补充 Linux 应用标识的用途默认值，以及连续录音时词表更新、清空和异常词条回归。
- Linux 仍使用 Whisper CPU 识别器，热词是拼写上下文，不保证与 Apple 的输出和准确率一致。真实麦克风、多语言效果及外部网关/note.md 确认仍需设备验收。
