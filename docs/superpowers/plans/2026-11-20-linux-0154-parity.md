# Linux 0.15.4：对齐 macOS 0.15.3

`git pull --ff-only` 将 main 从 `6d230e53` 更新至 `b248fc66`。本次上游仅修改共享 Flutter 输入历史界面及版本/文档；Rust 协议仍为 v14，未引入新的平台接口。

## 实现

- 同步单行历史、时间与来源列、多行标记、未发送标记、紧凑范围按钮。
- 共用点击行回填、⋮ / 右键菜单、悬停全文预览、复制到本机及本设备记录删除行为；不另写 Linux 专用副本。
- 新增 Linux 与 macOS 平台回归，核验 40px 搜索框/历史行、右键操作、全文预览、菜单打开与复制不会误触行回填、复制和回填保留完整多行内容。
- 发现并修复共享布局缺陷：320px 面板中的多行草稿同时带有行数和「没发出」时，原布局溢出 46px，两平台回归均失败。时间列保持对齐，但宽度上限改为整行的三分之一，窄列省略显示；修复后 21 项历史列表测试通过。

Linux 发布号为 **0.15.4**（Flutter 0.15.4+60），GitHub Latest 保持 macOS 0.15.3，Linux-only release 使用 `--latest=false`。

## 验证与边界

改动前相关编辑器、输入历史及资源页基线为 180 通过、1 跳过。完整回归、干净 worktree 打包及发布/安装结果另记于 `tasks/todo.md`。
