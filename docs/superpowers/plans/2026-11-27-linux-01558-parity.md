## 1. 差异审计

审查 `1adea012..01f8a912` 的 Linux 侧行为：

1. **Windows 版 A 段接线在 Linux 上的兼容性（`5e39bb91`：`feat/windows-foundation`）**：
   - `rust/Cargo.toml` 成员表新增 `host-windows` 与 `svc-windows`（非 Windows 下为空壳，编译零副作用），`rust/.cargo/config.toml` 仅对 `[target.x86_64-pc-windows-msvc]` 设 `+crt-static`，不影响 `x86_64-unknown-linux-gnu`。
   - `rust/cli/src/main.rs` 新增的空参数启动 GUI 与 `console_utf8` 严格包裹在 `#[cfg(windows)]` 内，Linux 下 `rapp` 启动脚本与 `rapp-cli` 行为完全不变。
   - `rust/service/src/instance.rs`、`rust/service/src/main.rs`、`rust/service/src/workers.rs`、`rust/term/src/unix_main.rs`、`rust/net/src/{config,datadir,log,private,proc,quic}.rs`、`services/state/src/disk.rs` 的 Unix / Linux 分支保持原有行为（抽象域套接字单实例锁 `com.rapp.service.<uid>`、`0600`/`0700` 权限位、PTY 服务与 shell hook 均不变）。
   - 执行 `cargo clippy --workspace --all-targets -- -D warnings`（顺手清理 `rust/client-gtk/src/focus.rs` 在新版 clippy 下的 `as_chunks_mut::<4>()` 告警，19 个 crate 全部零警告）与 `cargo test --workspace` 在真实 Linux x86_64 环境下完成全工作区验证。
2. **快捷区 `PgUp` / `PgDn` 与倒 T 方向键（`0.15.57` `feat/bar-pgup` + `0.15.58` `feat/quick-one`）**：
   - 第一行精简为 8 键 `Tab ⇧Tab Esc ⌃C ⌫ ⏎ ↑ ⋯`（移除 `⌄`，快捷区统一由输入块内的开关收起/展开）；第二行为 10 键 `⌘C ⌘V ⌘T ⌘ ⌃ PgUp PgDn ← ↓ →`，通过 10 列网格让 `↓` 对齐 `↑`、`→` 对齐 `⋯` 呈标准倒 T 布局，并移除方向键上滑出 `Home`/`End` 的手势。
   - `PgUp` / `PgDn` 在普通文本终端屏幕翻阅 rApp 本地回滚历史（每次 `rows - 1` 行，点其它快捷区按键自动回到最新），在 `less`/`vim` 等全屏（alt-screen）程序中透传 `PageUp` / `PageDown` 键，在应用会话中发送对应键码。
3. **测试与打包说明补齐**：
