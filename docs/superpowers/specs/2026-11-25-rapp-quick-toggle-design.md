# 快捷区开关并进输入框（⌨ 键）

2026-11-25。接 `2026-11-24-rapp-input-dock-design.md`。

## 为什么

快捷区收起后，块旁边剩一个 28 的小圆圈（⊙），和输入框、＋、发送的方圆角样式都不搭。用户的建议：把开关放进输入框，和 ＋、发送放在一起。

## 方案（用户选 A）

- **A 方键并排（选中）**：框里加一个和 ＋ 一样大小、一样样式的 ⌨ 键，排在 ＋ 左边。文本区收起时，⌨ 挪到「输入」旁边。任何时候都不再有单独的圆圈。
- B 和 ＋ 合成一个两格胶囊：更省地方，但 ＋ 的形状改了，触控目标也变小了。
- C 只放进 ＋ 菜单：最干净，但每次开关都要多点一下菜单，文本区收起时也没法开关。

## 设计

1. **框内 ⌨ 键**：放在输入框右侧 ＋ 的左边，顺序是 ⌨ ＋ 发送。尺寸、圆角、玻璃样式和 ＋ 一样，随放大档一起缩放。
   - 快捷区显示时，⌨ 亮起（和 ＋ 菜单打开时的亮法一样）；收起时是普通样式。
   - 点一下切换显示和收起（`setQuickHidden`），终端类和普通 App 仍然各记各的。
2. **去掉圆圈把手**：删掉 `QuickHandle`，删掉 `FloatingComposer` / `_Place` 里放把手的逻辑（右 → 左 → 上 → 下）。
3. **去掉快捷区行尾的 ⊙ 键**（`key_bar_keys` 的 `hide`）：开关只在 ⌨ 一处，按键区空出一格。iOS 和 PC 都一样。
4. **文本区收起时**，按钮栈里多一个 ⌨，排在「输入」旁边。样式和「输入」一样，用 stageButtonSize 的玻璃键，亮暗规则同上。只在能写字的会话（`composerAllowed`）里出现。按钮栈的高度和个数计算要算上它。
5. **不变的部分**：
   - 打字后自动收起；
   - ＋ 菜单「快捷区」一组；
   - 按住语音时快捷区不出现也不消失；
   - 块的拖动和记位置。
6. **无障碍和悬停提示**：⌨ 的标签随状态变，显示时是「收起快捷区」，收起时是「显示快捷区」。

## 留给实现的

- ⌨ 用哪个图标（Material 的 keyboard 或 keyboard_outlined），亮起时具体是什么颜色，都跟着 ＋ 的现有样式走。
- 很窄的屏幕加上大放大档时，框里多一个键会挤占文字的宽度：照现有的 ＋ / 发送一样处理，不另设规则。
