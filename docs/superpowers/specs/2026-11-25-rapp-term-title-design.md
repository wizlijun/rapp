# 终端名用程序标题、总览「终端」改为新建（短设计）

日期：2026-11-25。状态：**已定**（用户：“按你推荐的来”）。标【我定的】的是我替你做的选择，可以改。

## 0. 用户的要求（原话）

| # | 要求 |
|---|---|
| T1 | “现在启动一个新的终端，会话名一直显示 zsh、sh之类的，能否取到对应的terminal标题名，然后显示给用户。” |
| T2 | “在总览中点击 终端时，是打开已经打开过的终端。我希望是直接创建新的终端，打开应该改名为 新建。” |

为什么：几个终端都叫 zsh、zsh-2，分不清哪个是哪个。

## 1. 现状

- 名字在被控端的 `rapp-term run` 启动时定：取命令名（`zsh`），重名加后缀（`zsh-2`）；只有改名（设备页 ✎）会变。
- 程序用 OSC 0/1/2 设标题，rapp-term 的模拟器（alacritty `VoidListener`）把它丢掉了。
- rApp 各处（顶栏、全景、设备页、常用、项目、状态队列、需要你）都从设备的终端列表读名字：`termName` / `termDisplayName(r.name, r.host)`。
- 总览「常用 · 终端」走 `termsTarget`：文字模式先打开最近用过的文字终端，没有才新建。

## 2. 做什么

### 2.1 终端名用标题（T1）

1. **rapp-term 读标题**：在输出流里认 OSC 0 / 1 / 2（和 OSC 7501 同一个扫描器）。记两样：标签名（OSC 0、1）和窗口标题（OSC 0、2）。显示时**先用标签名，没有再用窗口标题**【我定的：oh-my-zsh 把标签名设成短目录 `~/git/rapp`，窗口标题是长的 `用户@机器:~/git/rapp`；Claude Code 用 OSC 0，两样都设】。
2. **清理**：去掉控制字符，去掉首尾空白，再去掉开头的非文字符号和空格。Claude Code 标题前转动的 `✳`、`⠂`（盲文点阵）这类符号要去，否则名字一直闪【我定的】。最长 64 个字符，超出截断。清理后为空，或程序发了空标题，就当没有标题。
3. **手动名优先（A）**：用 `run --name` 起的或改过名的终端，记为“手动命名”，不报标题，名字不变。只有没手动命名的才用标题代替 zsh。
4. **传到 rApp**：被控端的会话状态（本机 socket 的 `status`）和终端列表的行，各加一个可选字段 `title`，没有就不写。rApp 的 `TermRow` 加 `title`，显示名 = `title ?? name`。凡是现在用 `r.name` 显示的地方都改用显示名。改名框的初始文字也用显示名。
5. **兼容**：字段是新增可选的，协议仍是 v15。旧设备不发 `title`，照旧显示 zsh；旧 rApp 不认这个字段，也照旧。`name`（zsh、zsh-2）本身不变，照旧保证不重名。
6. Linux 的 rapp-term 是同一份 Rust 代码，跟着一起有。

### 2.2 总览「终端」新建（T2）

- 总览「常用 · 终端」那一格：文字模式，并且这台设备有能开终端的窗口时，**点了总是新开一个文字终端**，用默认 shell，在你给这台设备选的终端窗口里开。格子右边写「新建」，读屏写「常用 终端，点按新建」。
- 画面模式（或设备没有能开终端的窗口）：照旧打开终端 app 的画面，写「打开」【我定的】。
- 设备没有终端窗口：照旧提示。
- 不改【我定的】：设备页的「终端」入口（下面已有按 shell 新建的按钮），项目的「全部打开」（否则每点一次多一个终端），打开应用菜单。

## 3. 办法（考虑过的）

- **A 被控端从输出里读标题，随终端列表发来（选这个）**：rapp-term 本来就看着全部输出、已经在认 OSC 7501；rApp 不用开着画面也知道名字。
- B rApp 从画面数据里读：只有正开着看的终端才有画面数据，列表里其他终端拿不到。
- C 读前台进程名（如 `vim`、`claude`）：拿得到，但看不出目录和任务；以后可以作为“程序不设标题时”的补充，这次不做。

## 4. 不做

- 不读前台进程名、当前目录（程序不设标题就仍叫 zsh）。
- 标题不存历史，不进状态队列。
- 不改 `name` 的规则和改名规则。

## 5. 验收

- 装了 oh-my-zsh 的 zsh：新开后名字是 `~/目录`，`cd` 后跟着变；跑 `vim x` 时变成命令，退出后回到目录。
- Claude Code：名字是它的任务标题，开头没有转动的符号，不闪。
- 改过名的终端：名字一直是改的那个。
- 不设标题的 shell：仍是 zsh / sh。
- 旧版被控端：照旧显示 zsh。
- 总览「常用 · 终端」：写「新建」，点两次开出两个新终端；画面模式写「打开」，照旧。
