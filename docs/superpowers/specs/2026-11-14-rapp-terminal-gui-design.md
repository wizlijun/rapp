# rapp 终端会话：界面设计

日期：2026-11-14。状态：**第 1 稿，待用户审。** 本文不改代码。

这一份管终端会话在主控台上的样子和手感，是终端会话规格（`2026-11-14-rapp-terminal-sessions-design.md`，下称“规格”）里 T1–T3 的界面那一半。被控端（`rapp-term`、service、hub）已经做完，见两份计划 `2026-11-14-rapp-term-core.md`、`2026-11-14-rapp-term-serve.md`。

- 可点原型：`2026-11-14-rapp-terminal-gui-prototype/`，也在 <https://claude.ai/artifact/53xhLBQEtGn3VdDeDJvutH>。数据全是示例。
- 输入区照《输入区：写作面板》（`2026-11-14-rapp-composer-writing-panel-design.md`，下称“写作面板”）。
- 网络标记、断开后的话和按钮照《网络状态》（`2026-11-14-rapp-network-status-design.md`）。

标【我定的】的是我替你做的选择，可以否掉。标“未实测”的只凭文档或记忆。

## 0. 用户的要求（2026-11-14，原话）

- “现在开始做 teminal 远程查看和控制功能的GUI，先加载对应的设计，做出原型图我来看看”
- “输入框的体验，请保持另一个设计的一致。请先再设计好其他部分，让整个终端功能比最好的终端体验对齐。”

## 1. 一句话、目标、不做、不能出现

**终端会话在主界面里用起来，要像一款好的本地终端：点一下就能打字，滚动、查找、选中复制都是本机的手感；写一段话时用写作面板。**

目标：

- G1 画面是一张对得齐的字符网格：中日文、框线、颜色、光标都对。
- G2 舞台有焦点时，键盘上的键都到终端，rapp 不截。
- G3 往上翻、查找、选中复制在本机完成，不进 tmux 的复制模式，不打扰那边。
- G4 输入区和 app 会话是同一个写作面板，行为一样。
- G5 没有实体键盘时也能打断、选选项、确认。
- G6 不点开就看得出每个终端在干什么、停没停。

不做（这一版）：

- 把鼠标点击转发给终端里的程序；按 tmux 的布局把几个面板并排显示；提示符之间跳转；把那边的 tmux 缓冲区收进资源面板。这四样列在 §8“以后”。
- 输入时的本地预测回显（mosh 的做法）。弱网下写字用写作面板，它本来就在本机【我定的】。
- 在舞台上用输入法组字。中文、日文在写作面板里写【我定的】。
- 只读锁、终端配色的自定义、连字。

不能出现的（做成了也算失败）：

- 写作面板或按键排盖住终端的最后几行。
- 滚到历史里看东西时，新输出把画面拽回底部；或者选中的文字因为刷新丢了。
- 开合写作面板、开关按键排、切标签，让那边的终端改了尺寸。
- 规格 §1 列的那几条（改别人的尺寸、动用户的 tmux 设置……）。

## 4. 规则

### 4.1 画面

D1. 按格子画：每个字的位置由它的列号决定，不由字体的宽度决定；宽字符占两格。框线和方块字符画成线和块，上下左右接得上【我定的】。

D2. 字体用设计语言的等宽字体，中文回落照设计语言 §5。不开连字。

D3. 颜色：默认前景、背景取主题的 `--text`、`--bg`；16 个基本色每套主题各定一组，保证在该主题底色上对比度不低于 4.5:1；256 色和真彩色原样显示。粗体、暗淡、斜体、下划线、删除线、反显都画【16 色的具体取值留给实现，原型里是一组示例】。

D4. MATRIX 主题的文字光晕不加在终端里（和写作面板 W2 一致）【我定的】。

D5. 光标：位置、显示与否跟那边；舞台有焦点时是实心块，焦点在别处时是空心框；不闪（设计语言：只有“等你”会闪）【我定的】。光标形状（块、竖线、下划线）跟那边，取不取得到见 §6。

D6. 只重画变了的行。

### 4.2 尺寸和字号

Z1. 尺寸规则照规格 §8.3：没有别的终端接着，按舞台设行列数；有，就不动，缩小显示。

Z2. 写作面板和按键排不占行数：它们出现时，画面整体上移 64，行列数不变（和写作面板 W4 是同一条规则）。上面被移出去的三行是最不要紧的。

Z3. 字号可调，六档（12、13、14、15、16、18），默认 14，记在这台主控台上【我定的】。⌘＋、⌘－，或流量标签菜单里的两个按钮；以后的触屏目标加捏合。

Z4. 字号变了、舞台大小变了（改窗口大小、进出全屏）：没有别的终端接着时，停手 0.3 秒后按新的行列数重排一次；画面中间显示新的行列数约 1 秒。

Z5. 有别的终端接着时，字号只在“原样”显示下起作用；“适应宽度”时字号由宽度决定。

### 4.3 往上翻

H1. 两指滚动、滚轮、PageUp（焦点不在终端程序上时）就是往上翻，本机滚，带惯性。历史分批向那边取，取过的留在本机。

H2. 离开底部以后，新输出不移动画面；底部中间出现一个条「正在看历史 · 回到最新」，有新输出时写「有新输出 · 回到最新」。

H3. 按任何会发给终端的键，或者从写作面板发送，画面回到最新。

H4. 右边有一条细的位置标记（需要历史总行数，见 §6）。

H5. 备用屏幕（vim、less、htop 这类全屏程序）没有历史。这时滚动改成给程序发上、下方向键，一格三行【我定的，未实测】。

### 4.4 查找

F1. ⌘F（macOS）/ Ctrl+Shift+F（其他），或流量标签菜单里的「查找…」。查找条在舞台右上角：输入框、`第几处/共几处`、上一处、下一处、关闭。

F2. 找的是屏幕加全部历史。打开查找时在后台把还没取的历史取完，取的时候写进度。

F3. 全部命中处描边，当前这一处反白，画面滚到它。默认停在最新的一处；回车往更早找，Shift+回车往更新找。Esc 关闭。

F4. 不分大小写；不做正则【我定的】。

### 4.5 选中和复制

C1. 拖动按格子选；双击选一个词（路径、网址算一个词）；三击选一行；Shift+点击延长；按住 ⌥ 拖是矩形选区。选到边上时自动滚。

C2. ⌘C（macOS）/ Ctrl+Shift+C（其他）复制到本机剪贴板。选中以后左上角出现「选中了 N 个字 · 复制到本机」，给没有键盘的时候用。不做“选中即复制”【我定的】。

C3. 复制出来的文字：折行接回原来的一行（见 §6），行尾空格去掉。

C4. 刷新不丢选区：选区记的是“哪一行的哪几列”，那一行内容变了才取消。

C5. 历史里的文字一样可以选。

### 4.6 链接

L1. 屏幕上的网址加下划线。⌘+点击（macOS）/ Ctrl+点击（其他）用本机浏览器打开；触屏上点一下出现「打开 · 复制」【我定的】。

L2. 那边的文件路径不做成链接。

### 4.7 键盘

K1. 点一下舞台，焦点就在终端：可见字符、回车、退格、Tab、Esc、方向键、Home、End、PageUp、PageDown、F1–F12、Ctrl 加字母、Shift+Tab 都发过去。

K2. rapp 自己的快捷键只用这两组，别的一律不截【我定的】：

| 做什么 | macOS | 其他 |
|---|---|---|
| 复制 | ⌘C | Ctrl+Shift+C |
| 粘贴 | ⌘V | Ctrl+Shift+V |
| 查找 | ⌘F | Ctrl+Shift+F |
| 字大、字小 | ⌘＋、⌘－ | Ctrl+Shift+＋、Ctrl+Shift+－ |
| 打开写作面板 / 焦点来回 | ⌃⌘I | 写作面板那份文档 §10 还没定；终端里 Ctrl+I 就是 Tab，不能用 |

K3. Option 键当 Meta 用（发 Alt 组合），不用来打特殊字符【我定的；协议里现在没有 Alt 组合，见 §6】。

K4. 在舞台上粘贴（K2）：一行以内直接贴进去；多行不直接进终端，而是打开写作面板，把内容放进去让你看一眼再发（规则照写作面板 W14：短的进文字，长的成块）【我定的】。理由：多行贴进一个没开括号粘贴的 shell，每一行都会被执行。

K5. 舞台上不接输入法。检测到在组字时，提示去写作面板。

K6. 发出去的键还没有在屏幕上看到回应、超过 0.3 秒时，光标后面跟一个省略号，回应到了就消失【我定的】。键按顺序发，不丢、不重排。

### 4.8 输入区和按键排

W1. 输入区就是写作面板，W1–W14 全部适用。终端会话的不同只有四处：

| 写作面板里的 | 在终端会话里 |
|---|---|
| 空着时的灰字“写给 <app 名>” | 写当前面板的命令名，如“写给 claude” |
| 「＋」里的“附件…” | 灰着，写“终端会话不支持”（规格 §13） |
| 「＋」里的“在远端复制” | 没有（终端里选中就能复制） |
| 「＋」里的按键一组 | 换成终端的一组，15 个：Esc、Tab、⇧Tab、删除、回车、←、↓、↑、→、⌃C、⌃D、⌃L、⌃R、PgUp、PgDn |

W2. 发送：整段作为一次粘贴发过去，补不补回车照 app 配置的 `afterSend`；等那边回“已粘贴”才清空。空着按回车给终端发一个回车。

W3. **按键排**是一个开关，在「本机」菜单里，记在这台主控台上；桌面目标默认关，以后的平板目标默认开【我定的，改了规格 §2 草图里“按键常驻在右下角”】。理由：有实体键盘时这些键就在手边，常驻一排只是挡画面；Blink 也是接了键盘就收起。

W4. 按键排打开时：左下角 Esc、⌃C、Tab，右下角 ↑、↓、回车，各 52×48；写作面板在中间。舞台窄到放不下两边时（不到 1100 宽），按键排移到写作面板上面一行，画面再上移一行。

W5. 按键排上只有这六个；其余的在「＋」里。

### 4.9 标签和窗口

T1. 一个面板一个标签（规格 §2）。标签按 tmux 的窗口、面板顺序排；一个窗口里只有一个面板时写 `1 claude`，有几个时写 `2.1 nvim`、`2.2 logs`。

T2. 顶栏第二行在设备、路径后面写当前面板的标题（终端程序自己设的那个，Claude Code 会把正在做的事写在里面）。会话列表的第二行也带上它。

T3. 标签右边一个「＋」：在这个会话里新开一个窗口，目录和当前面板相同【我定的】。这给 rapp 对 tmux 能做的四类事（规格 §8.1）里的“新开”加了“新开窗口”，仍然是用户点了才做。不提供关闭面板：结束程序是那边的事。

T4. 面板里的程序退出了：标签写“已退出”，画面留着，键不再发。

### 4.10 状态和提醒

N1. 状态灯、未读、“等你”照规格 §12 和设计语言，不另起一套。

N2. **响铃直接算“等你”**，不等 3 秒安静【我定的】。理由：响铃就是那边的程序在叫人，是不用猜的信号；Claude Code 可以设成需要人时响铃。

N3. 全景和设备面板列出在线设备上的全部终端，不管这台主控台打没打开过（规格 T3 的“不点开就看得出哪个停下来了”）。

N4. 流量标签左边的网络标记、断开以后舞台上的话和按钮，照《网络状态》§4。终端会话断开时，画面停在最后一屏，盖斜条纹，不收键。

## 5. 做法的选择

**网格怎么画**

| 做法 | 取舍 |
|---|---|
| **自己按格子画（已选）**【我定的】 | 对得齐，滚动和选区都在自己手里；要自己写选区、查找、链接 |
| 用 Flutter 的文字排版一行一行排 | 最省事；但中文字体的宽度不正好是英文的两倍，表格和框线会歪 |
| 嵌一个完整的终端仿真器控件 | 现成的选区和滚动；但它要的是字节流，和“只送最新一屏”的传法对不上，本机还多出一份会走岔的状态（规格 §3 已经否了字节流） |

**底部放什么**

| 做法 | 取舍 |
|---|---|
| **写作面板 + 可开关的按键排（已选）** | 和 app 会话一致；有键盘时画面干净；开合时画面上移一行，不改尺寸 |
| 常驻一条底栏（原型第 1 版） | 按键和输入框随时在；但和写作面板不一致，平白少三行 |
| 按键和「输入」浮在右下角（11-13 的交互稿） | 最省地方；但盖住终端最要紧的最后几行 |

**多个面板怎么摆**

| 做法 | 取舍 |
|---|---|
| **一个面板一个标签（已选，这一版）** | 协议现在就够；一次看一个 |
| 按 tmux 的布局并排显示 | 和 iTerm2 的集成一样好；但要面板的位置、要同时看几个面板，协议要加，放到以后 |

## 7. 界面一侧的结构

都在 `gui/lib` 下，纯 Dart，三个桌面平台同一份。

| 东西 | 做什么 |
|---|---|
| `TermSessionPort`（规格 §6 已定） | 连 hub 给的本机端口，说线协议，发出现有的 `SessionEvent` |
| 网格模型 | 当前屏、取到的历史、每行解析好的字和样式；只认颜色和字形转义的小解析器（规格 §7） |
| `TermStage` | 按格子画；滚动；选区；链接；查找的高亮；光标 |
| 键盘映射 | 本机的按键事件 → 线上的键名或文字；K2 的快捷键在这里分出去 |
| 查找条、按键排、尺寸提示 | 舞台上的三个小浮层 |
| 写作面板 | 用 `ComposerPanel`（写作面板 S1）。**依赖：写作面板 S1 要先做，或者和 G2 一起做** |
| 设备面板的“终端”一组、会话列表、全景的文字缩略、两个角菜单 | 在现有的 `devices_tab`、`sessions_tab`、`overview`、`stream_menu` 上加 |

## 8. 分步

每一步做完都能单独验收。对应规格 §16 的 T1–T3。

| 步 | 做什么 | 验收 |

## 9. 我定的，一览

1. 按格子画，框线自己画（D1）。

## 10. 要你确认的

1. **按键排默认关**（W3）。它改了规格里你确认过的“按键常驻”。
2. **响铃算“等你”**（N2）。
3. **「＋」新开窗口**（T3）：rapp 对你的 tmux 多做一件事。
4. **终端配色**：按原色，还是 MATRIX 主题下压成单色（原型的 Tweaks 里可以对比）。
5. 规格 §18 第 2 条还在：终端的未读算不算进顶栏“需要你”的数字。
