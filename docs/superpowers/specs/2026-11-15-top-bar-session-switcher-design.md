# 顶部栏：会话切换列表 + 菜单按钮只留图标（小改动）

日期 2026-11-15。用户需求原文三条：点当前会话处列出所有激活会话（按设备分组、显示状态）快速切换；本机菜单去掉文字、用三个点；远程菜单去掉文字、用三条杠。

## 为什么

现在换会话只能 ‹ › 一个个翻，或打开侧栏「会话」页（挤开画面、要关两次）。要一次点击就能看到全部会话并跳过去。菜单按钮的文字占地方，图标足够。

## 目标

1. 点顶部栏的会话块（状态灯 + 名字 + 第二行）弹出会话列表：全部已打开的会话，按设备分组，每行有状态灯和状态；点一行就切到它，列表关闭。
2. 本机菜单按钮：任何宽度都只显示图标，图标改为 ⋯（`Icons.more_horiz`）。
3. 远程菜单按钮：任何宽度都只显示图标，图标改为 ≡（`Icons.menu`）。
4. 最左的面板按钮从 ≡ 改为侧栏图标（`Icons.view_sidebar_outlined`），避免一条栏上两个 ≡（用户已定）。

## 不做

- 列表里不放「常用」里未打开的 app，不放开新会话的入口。
- 不改 ‹ › 的规则（有当前项目时仍只在项目内翻）。
- 不加键盘快捷键。
- 流量标签那个「三合一」菜单（窄栏时）不变。

## 做法（Approaches）

- **A. 复用 `CornerPopover`（选定）**：加 `Corner.sessions`，和 本机/远程/需要你 同一套开关、点外面关闭、遮罩、互斥、不透明浮层底色。
- B. Flutter `showMenu`：代码最少，但 Material 默认样式、没有分组标题、放不下两行行，且不和角落菜单互斥。
- C. 点会话块打开侧栏「会话」页：几乎零代码，但挤开画面、不快。

用户选 A。

## 设计

- **会话块变按钮**：整块可点，名字后加一个 ▾（`Icons.arrow_drop_down`，muted 色）。没有任何会话时不可点、不显示 ▾。点它 `toggleCorner(Corner.sessions)`；打开时会话块用 `raiseBox(border: t.text)`，和其他角落按钮打开时一样。语义标签保持原文，加 button。
- **弹出框**：`CornerPopover` 加一个对齐参数（默认贴右，保持现状；会话列表贴左：`targetAnchor: bottomLeft, followerAnchor: topLeft`）。宽 340，最大高度沿用。
- **列表内容**：`groupSessions(entries, Grouping.device, ...)`，固定按设备分组，与侧栏的分组设置无关；分组标题是设备名。行用侧栏「会话」页同一个行组件（把 `_SessionRow` 提成共用的 `SessionRow`，`byDevice: true`）。当前会话那行描边（selected）。点一行：`state.select(key)` 并关闭列表。选到当前项目以外的会话时，行为和侧栏一样（不改当前项目）。
- **菜单按钮**：`MenuCornerButton` 不再显示文字，宽 48；本机 ⋯、远程 ≡；外框颜色规则不变（本机 line，远程 accent 1.5px，打开时 text）。Tooltip 和语义标签不变。顶部栏里按 `words`（≥1000）算的按钮宽度改为固定 48。

## 留给实现者

- `menuButtonWidth` 若不再有人用就删掉。
- 测试：点会话块出列表、按设备分组、显示状态、点行切换并关闭；与 本机/远程 菜单互斥；无会话时不可点；宽栏（≥1000）时两个菜单按钮也没有文字；三个图标。
