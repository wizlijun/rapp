# 总览：没有 host 服务的「本机」列默认折叠

日期：2026-11-26　状态：已批准（2026-11-26）

## 为什么

iPad / Duo 上本机不跑 host 服务，总览「本机」列只有名字、灯、余力、「没有打开的 app」、版本号，
却占满 220px 一列。默认折成一条窄条，把横向空间让给有会话的设备列。

## 范围

- 只折**没有本机服务**的「本机」列：`Overview.monitor == null` 且列 `id == null`。
  桌面（macOS / Linux / Windows）一定有 `ServiceMonitor`，所以不受影响。
- Mac 本机列、所有远程设备列保持原样（用户选定）。
- 非目标：不存盘记住折叠状态；不加设置项。

## 做法（只有一种合理做法）

在 `gui/lib/ui/overview.dart` 的 `_Column` 里加折叠形态，展开状态放在一个小的有状态 widget 里，
只在本次运行内保持。不放进 `MainState`（没有别处要读它），也不放 prefs（用户没要求记住）。

- **折叠形态**：宽约 56px 的竖条，`panelBox` 边框，自上而下：系统图标（`OsMark`）、状态灯、
  名字「本机」（单行，过长省略）。整条可点，语义标签「展开 本机」。key `column-local`，
  折叠条本身 key `column-local-folded`。
- **展开形态**：和现在一样，列头名字右侧多一个小的折回按钮（key `column-local-fold`，
  语义「折叠 本机」）。
- 默认折叠；点开后在本次运行内保持展开，直到再点折回。

## 留给实现者

- 竖条的具体间距、名字字号，按现有 tokens 取。
- 现有测试里不传 `monitor` 的总览测试会看到折叠的本机列；需要展开内容的测试先点开，
  或改为断言折叠形态。
