# 滚动复制（协议 v9）验收记录

日期：2026-11-14。规格：`2026-11-14-rapp-scroll-copy-design.md` §7。分支 `feat/scroll-copy`。

本记录分两部分：自动化测试的实测数字（已有），和需要在用户的 Mac 上做的真机项（**待真机验收**，没有编造任何数字）。
对照基线：`main` 上的 0.7.1。

## 一、自动化证据

### 单元测试
`swift test --filter RappCoreTests.ScrollCopyTests`：14 个测试全部通过（含随机帧序列下主机模型与解码画布逐字节一致、四条边改尺寸没有整帧、静止后修正恢复精确量化）。
`RappCoreTests` 的 Swift/Rust 同一组帧数据交叉测试见 Task 3 的记录。

### 字节比例（开复制 / 关复制，非首帧）
这两个测试只断言上限，不打印比例。下面的数字取自 Task 4 的测试记录（`task-4-report.md`），不是本次重新测出的；本次重跑确认断言仍然通过。

| 场景 | 上限（断言） | gray4 | color16 | duogray + 原始样本 |
|---|---|---|---|---|
| 终端，640×480 | ≤ 20% | 6.5% | 6.4% | 7.1% |
| 网页，固定顶栏 60 / 侧栏 200，每帧滚 37 px，832×640 | ≤ 40% | 23.8% | 24.2% | 24.3% |

### S5 耗时：`RAPP_PERF=1 swift test -c release --filter RappCoreTests.ScrollCopyPerfTests`（本次实测，1080p，release）
| 场景 | 开复制 ms/帧（字节） | 关复制 ms/帧（字节） | 差值 |
|---|---|---|---|
| 网页滚动，duogray 原始样本 | 5.53（1196175） | 37.41（9697884） | -31.89 ms |
| 网页滚动，color16 | 4.37（1206979） | 40.81（9661638） | -36.44 ms |
| 噪声（找不到可复制的行，最坏情况），duogray 原始样本 | 76.03（10552198） | 74.01（10552198） | +2.02 ms |
| 噪声，color16 | 49.80（62251830） | 48.94（62251830） | +0.86 ms |

目标"开/关复制差值 ≤ 3 ms"：最坏的噪声场景 +2.02 ms，通过；真实滚动场景开复制反而快 30 ms 以上。
（该测试在 30 s 内跑完，场景是合成的，机器是本次开发机，不同机器绝对值会变。）

## 二、真机验收（待真机验收）

准备：两边都 `swift build -c release`，按 README 起主机和客户端；基线用 `main` 上的 0.7.1（同一台 Mac、同一窗口、同一内容）。
主机每秒统计看 `service.log` 的 `[stats]` 行（kbps、`fulls`、`encMs`）。

| 项 | 步骤 | 通过条件 | 结果 |
|---|---|---|---|
| S1 终端 | 终端里连续输出（`yes \| head -n 100000` 或 `seq 1 200000`），本机像素密度，双色·灰度和高彩各 30 秒，记录每秒 kbps 的总量 | 比 0.7.1 少 80% 以上 | 待真机验收 |
| S2 网页 | 有固定顶栏和侧栏的网页，滚轮上下滚 30 秒，记录总字节 | 比 0.7.1 少 60% 以上 | 待真机验收 |
| S3 改尺寸 | 依次拖动窗口上下左右四条边，看每秒统计的 `fulls` 和画面 | 拖动期间 `fulls` 为 0；画面没有黑屏扫过 | 待真机验收 |
| S4 停下 | 双色·灰度下滚动后停下 1 秒，看统计 | 停下后约 300 ms 有一次小流量（修正片）；`fulls` 为 0；肉眼看文字不比 0.7.1 糊（逐像素一致由单元测试保证） | 待真机验收 |
| 弱网档 | 双色·灰度 + 密度 1.0 下重做 S1、S2 | 终端比 0.7.1 少 80% 以上；网页只记录数字 | 待真机验收 |
| S5 真机 encMs | 1080p 窗口持续滚动，记录 `encMs` | 只记数字（0.7.1 没有这项统计） | 待真机验收 |

没达到的项如实记录，不要调测试去凑数字。

## 三、调参旋钮（给验收后调优的人）

- `maxRepeats = 4`（`Sources/RappCore/ScrollDetect.swift`）：一个 64 px 条里，某行指纹在旧画面中重复超过 4 行就不投票。
  满屏相同行的画面因此不发复制块：结果正确，但不会更省。如果真机上终端空行多、码率降得不够，先看这个值。
- 静止后修正：最后一次带近似的帧之后 300 ms，发送队列为空且没有挂着的邀请时，主机重编最后一帧（只含样本，无复制和搬画布）。服务器每 100 ms 调一次 `settleIfIdle()`。
- 片大小：32 KB，首片 8 KB，没有改动。
