## 1. 目标与非目标

目标：
- 把常用的 app 标出来，没打开时也在会话列表底部出现，点一下打开。
- 建项目，把几台设备上的几个 app 归到一起，一键全部打开、全部结束；会话列表能按项目分组。

非目标：多选、拖拽排序、项目间共享、和 Tower.md 同步（S8）、项目级的串流设置。

## 2. 用户看到的行为

### 2.1 常用

- 设备面板里远程设备的每个 app 行有「设为常用」，已是常用时显示「取消常用」。本机不列 app，所以没有常用。
- 会话列表最后一组「常用」：所有常用但还没有会话的 app，每行一盏"未打开"灯（虚线框）、app 名、设备名；点一下打开（等同设备面板里的「打开」）。打开后它从这一组移到上面的分组里。
- 删除设备时，它的常用一起删掉。

### 2.2 项目

- 左侧面板第三个标签「项目」（720px，主界面规格 §3.7），S1 里是占位，S5 实现。
- 每个项目一张卡：
  - 标题行：项目名（点一下改名）、一排灯（每个成员一盏，状态同它的会话；没会话就是"未打开"）。
  - 两个按钮：「全部打开」、「全部结束」（点两次，主界面规格 §5 第 4 条）。
  - 成员逐行：「<app> @ <设备>」、Agent 任务标签（可空，点一下编辑，一行文字）、状态文字、「打开 / 切到 / 重连」、「移出」。
- 「新建项目」在标签页顶部：输入名字，回车建好一张空卡。
- 往项目里加成员：卡片底部「添加 app」，展开一个列表，列出所有在线设备上的 app（来自探测结果）和所有常用，点一下加入。同一（设备, app）可以属于多个项目。
- 删除项目：卡片右上角「删除项目」，点两次。只删项目，不结束会话、不改常用。
- 「全部打开」：按成员顺序逐个打开，已打开的跳过，已断开的重连；离线设备上的成员跳过并在提示里写「<设备> 离线，跳过 N 个」。打开完停在第一个成员的会话上，面板收起（选了就收）。
- 「全部结束」：结束该项目所有成员当前的会话（属于别的项目的也一起结束，提示里写数量）。

### 2.3 按项目分组

- 会话列表的分组切换从「按设备 / 按 App」变成「按设备 / 按 App / 按项目」。
- 按项目时，每个项目一组，组名是项目名；不属于任何项目的会话放在最后一组「其他」。属于多个项目的会话在每个组里都出现。
- 顶栏当前会话第二行：「<设备> · <项目名>」（属于多个项目时写第一个项目加「等」），有 Agent 任务标签时再加「 · <标签>」。

### 2.4 存储

- 常用和项目存在 GUI 的配置目录里一个新文件 `workspace.json`（和 S1 的 `gui.json` 同目录），先写临时文件再改名，保证不出现半个文件。
- 内容：`{"version":1,"favorites":[{"device":"<id>","bundle":"<bundle id>","name":"<app 名>"}],"projects":[{"id":"<uuid>","name":"…","members":[{"device":"…","bundle":"…","name":"…","task":"…"}]}]}`。
- 文件坏了或版本不认识：用空的，提示「项目和常用没有读到，已从空白开始」，并把坏文件改名成 `workspace.json.bad` 留着。
- 写不进去：提示「项目和常用没有保存：<原因>」，内存里的照常用。
- 不存密码、令牌、会话内容。

## 3. 接口改动

- 只动 GUI（Dart）：`MainState` 增加 favorites / projects 和对应的操作；新文件 `workspace_store.dart` 负责读写；项目标签页、常用组、分组切换。
- hub 不变：打开、结束沿用现有命令；app 名来自现有探测。

## 4. 拆分建议

1. `workspace.json` 读写（坏文件、写失败）和 MainState 里的数据模型。
2. 常用：设备面板按钮、会话列表「常用」组。
3. 项目标签页：新建、改名、删除、成员增删、任务标签。
4. 全部打开、全部结束。
5. 按项目分组、顶栏第二行。

## 5. 验收

- 设为常用后，会话列表底部出现它；点一下打开、嵌入；结束后它回到「常用」组。
- 建项目、加两个成员、「全部打开」：两个都开，停在第一个；「全部结束」点两次后都结束。
- 按项目分组时，属于两个项目的会话出现在两组里。
- 退出再开，常用和项目都在。
- 手动把 `workspace.json` 写坏：启动后提示，空白开始，坏文件留着。
- 测试用临时目录，不碰用户真实配置。

## 6. 我做的假设（按默认执行，验收时可改）

1. **同一（设备, app）可以属于多个项目。**
2. **「全部结束」也结束属于别的项目的同一会话**（同一（设备, app）只有一个会话）。
3. **删除项目不结束会话。**
4. **Agent 任务标签只是一行文字**，rapp 不解释。
5. **常用和项目存在本机 GUI 配置目录**，不同步到别的设备。
