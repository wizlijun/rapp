# 顶栏子窗口：从一排 tab 改成一个「窗口」下拉（小改动设计）

日期：2026-11-16。对象：`gui/lib/ui/top_bar.dart` 的子窗口 tab 区。

## 为什么

用户的话：顶栏那排 tab **总宽度不够，不适合做这个事**。现在每个窗口一个 chip（最宽 200px）挤在一个横向滚动区里，旁边还常驻一个「已隐藏 N 个」chip（预算里占 130px）。窗口一多就横向滚，标题被截断，和顶栏其它东西抢宽度。

改成：**顶栏只显示当前窗口的标题，有其它窗口时点开下拉菜单切换**。宽度从"不封顶的一排"变成"一段可截断的标题"。

## 目标

1. 顶栏里窗口这件事只占一个控件，宽度有上限，窄了能继续缩。
2. 当前窗口标题一直看得见，位置固定。
3. 切窗口、关窗口、两条窗口规则、已隐藏窗口，功能一条不少。

## 非目标

- 不改 `WindowTabs` 的选中/MRU 模型，不改 `selectWindow` / `closeWindow` / `hideLike` / `noComposerLike` / `showHiddenOnce` / `unhide` 这些 state API。
- 不改终端的「＋」新建（它在 composer_plus 里，和顶栏无关）。
- 不改会话块（切会话的那个下拉）。

## 反目标（即使功能都在也算失败）

- 顶栏又多出一段会把别的东西挤掉的弹性宽度。
- 切会话和切窗口被混成一个菜单，用户误选。
- 当前在哪个窗口，要点开菜单才知道。

## 考虑过的做法

| | 做法 | 取舍 |
|---|---|---|
| **A（选中）** | 独立的「窗口 ▾」按钮，放在原 tab 那段位置，菜单里列全部窗口 + 已隐藏组 | 字面对应用户要的；一个控件换掉一排 chip 和一个常驻 chip |
| B | 并进会话块：第二行显示窗口标题，菜单上半切会话、下半切窗口 | 顶栏一个 ▾ 都不增加，最省宽；但一个菜单装两种东西，误选代价不同——用户选 A 后弃 |
| C | 只显示图标 + 窗口数（▣3），标题只在菜单里 | 最省宽，但看不到当前窗口标题，和需求冲突——弃 |

用户选 A。

## 设计

**控件**：新 `gui/lib/ui/window_menu.dart`，`WindowMenu`。放在现在 tab 滚动区的位置（远程菜单 ≡ 之后）。原来的 tab 滚动区和「已隐藏 N 个」chip 一起删掉。

**按钮长相**（沿用 `TabChip` 的外观，保持顶栏一致）：

```
[▣ 终端 — vim   ▾]        宽：内容自适应，最大 200
[▣ 终端 — vim]            只有一个窗口：没有 ▾，不可点
[▣ 3]                     窄：只剩图标和窗口数，完整标题进 tooltip
```

- 标题取当前窗口的 `title`，空的时候用 `appName`（和现在 tab 的规则一样）。
- ▾ 只在"有得切"时出现：窗口 ≥2，或有隐藏窗口。
- 有隐藏窗口且 A 的焦点在隐藏窗口上（`hiddenFocused`）时，按钮用 `selected` 样式——这是现在「已隐藏」chip 的提示，不能丢。
- 宽度参与顶栏现有的 `fixed()` 预算：它是**非弹性**的固定上限控件（≤200，最小 48），替掉原来 `chip = 130` 那一项；它不再使用 `Flexible` + 横向滚动。

**菜单**（用 `showMenu`，和现有的 tab 右键菜单、已隐藏菜单同一套）：

```
┌──────────────────────────┐
│ 窗口                     │   ← 分组标题
│ ● 终端 — vim           × │   ← 当前窗口：选中样式；× 关闭
│   设置                 × │
│ ────────────────────────  │
│ 已隐藏 2 个              │   ← 只有存在隐藏窗口时
│   偏好设置               │
│     这次显示             │
│     不再显示             │（沿用现有两项：这次显示 / 不再隐藏）
└──────────────────────────┘
```

- 点一行 = `selectWindow(id)`。
- 行右侧的 × = `closeWindow(id)`；主窗口和终端 pane 没有 ×（和现在一致）。
- **在菜单行上右键** = 现在 tab 的右键菜单：`隐藏这类窗口`（主窗口置灰）、`这个窗口不要输入区`，snackbar 和撤销不变。终端没有右键菜单。
- 已隐藏那一组就是现在 `_hiddenMenu` 的内容，搬进来，不再单独占一个 chip。

**终端**：同一个控件显示当前 pane 的标题，菜单里列 pane；没有 ×、没有右键、没有隐藏组。

**不显示的情况**：没有会话、会话已分离（`rs.detached`）时和现在一样不显示。

## 留给实现

- `showMenu` 的行里放 Row（标题 + ×）和包一层右键手势，具体 widget 结构、Key 命名由实现定。
- 顶栏宽度常量怎么接进 `fixed()` 由实现定，但必须保证：窄到极限时窗口控件先缩成图标，而不是把别的按钮挤出去。
- 测试：改写 `gui/test/ui/top_bar_test.dart` 的 `window tabs` 组（tab 出现/切换/选中、右键两条规则、已隐藏 chip 的四个用例），新增窄宽度下缩成图标、单窗口无 ▾ 两个用例。
