# 快捷区第二行：⌘T、单独的 ⌘ 和 ⌃（2026-11-27）

## 用户的话

「快捷键盘 more 栏里去掉一个不常用的，增加一个 cmd+T 放在第三个，再插入一个单独的 cmd、单独的 Ctl 键，按下后是按下状态，等用户输入其他字符做组合输入。后面那些 ctrl 的组合键可以都去掉了。」

为什么：⌘T 现在是新建终端的主要入口（等候卡片就是为它做的），iPad/手机上却没有按 ⌘T 的办法；⌃ 组合键一个一个摆出来占地方，单独的 ⌃ 加字母就能打出全部。

## 用户定下的三件事

1. 去掉的「不常用的」是 **⌥**。
2. 第一行的 ⌃ **挪到第二行**（第一行不再有 ⌃）。
3. 文本终端里单独的 ⌘ + 字母 **当作 rApp 快捷键**，和实体键盘在终端上按一样。

## 改后

- 第一行（10 个）：`Tab ⇧Tab Esc ⌃C ↑ ↓ ⌫ ⏎ ⋯ ⌄`
- 第二行（7 个，终端和应用一样）：`⌘C ⌘V ⌘T ⌘ ⌃ ← →`
- 去掉：⌥、⌃O ⌃R ⌃T ⌃B ⌃L。

## 各键怎么动

- **⌘T 键**：终端里 = 实体键盘 ⌘T（在旁边新建终端，走等候卡片）；应用会话里 = 把 ⌘T 发给那个应用。
- **⌘ 键**：和 ⌃ 一样是粘滞键（点一下亮一次，再点锁住，再点关）。
  - 应用会话：和现在一样，下一个键连着 ⌘ 发给被控 Mac。
  - 文本终端：下一个字母是 rApp 的快捷键：C 复制选中、V 粘贴、T 新建终端、W 结束终端（能结束的设备上，先问）。别的字母什么也不发，⌘ 用掉。⌘ 和 ⌃ 同时亮时 ⌘ 优先。⌘ 亮着点快捷区的其它键（← → 等）照常发送，⌘ 用掉。
- **⌃ 键**：和现在第一行那个完全一样，只是换了位置。

## 我定的（可改）

- 收起第二行（再点 ⋯）时，亮着的 ⌃ ⌘ 一并松开：键看不见了还亮着，下一个字母会莫名变成组合键。
- 终端里的 ⌘ 快捷键由终端画面在会话上挂一个处理函数（和现在的复制一样），快捷区和直接打字都走它，跟实体键盘是同一份代码。

## 不做

- 终端里 ⌘ + ←/→ 不变成 Home/End。
- 不加 ⌥ 的替代入口。

## 方案

只有一种合理做法：改 `keyBarRows` 的两行、加一个 ⌘T 键，终端里 ⌘ 走会话上的快捷键钩子。另一种是快捷区自己调 `newTermFrom` 等，但那样会和终端画面的 ⌘T/⌘W/复制各写一份，违反「一处实现」。
