# rapp 设计语言

日期：2026-11-12。状态：随主界面原型一起与用户确认；本文待用户审阅。

配套文档：`2026-11-12-rapp-main-window-design.md`（界面结构和交互）。
原型：Artifact「rapp 总管主界面」 https://claude.ai/artifact/PjqK1m3remVLyerH22JNBC 。

## 1. 五条原则

1. **颜色只表示"要你处理"**。每套主题只有一个强调色，只用在已断开和等你上。设备、项目、类型都不占用颜色。
2. **状态靠形状区分**。七种状态各有一个形状，不看颜色也能分清。
3. **只有"等你"会闪**。连接中只转不闪，其余全部静止。正常的东西不抢注意力。
4. **远程窗口优先**。常驻的只有顶栏；其余都是浮层，只盖不挤。
5. **上面收，下面发**。从 A 来的东西（流量、A 的剪贴板、串流设置）在窗口右上角；发给 A 的东西（文字、附件、按键）在窗口底部。

## 2. 状态灯

灯的基准尺寸是 10px，出现在所有列出会话、设备、app 的地方。

| 状态 | 形状 | 颜色 | 动静 | 所在行的底纹 |
|---|---|---|---|---|
| 活动 | 实心圆，带光晕 | `--on` | 静止 | 无 |
| 空闲 | 空心圆，2px 实线 | `--muted` | 静止 | 无 |
| 连接中 | 空心圆，2px 虚线 | `--on` | 旋转，1.4 秒一圈 | 无 |
| 已断开 | 实心三角，12×11px | `--accent` | 静止 | 135° 斜条纹，8px 一条，`--tint` |
| 等你 | 实心菱形，9px 方块转 45° | `--accent` | 闪烁，1 秒一次 | 整行铺 `--tint` |
| 离线 | 空心圆，2px 点线 | `--muted` | 静止 | 点阵，8px 间距，`--line` |
| 未打开 | 小方块，8px，圆角 2px | `--line` | 静止 | 无；边框改虚线 |

规则：
- 一个会话同时"活动"和"等你"时，灯显示等你。
- 已断开和等你的行，边框也用 `--accent`。
- 当前选中的行，边框用 `--text` 并加 1px 内描边。
- 图例固定放在左侧面板底部，用同一套灯。

## 3. 其他编码

| 信息 | 编码 |
|---|---|
| 流量 | 五格电平，格宽 3px，高度 4 到 12px 递增；亮格 `--on`，暗格 `--line`。0 亮 0 格，小于 5 KB/s 亮 1 格，小于 15 亮 2 格，小于 40 亮 3 格，小于 100 亮 4 格，其余 5 格。旁边用等宽字写数字 |
| 路径 | 一段 20px 的线：局域网实线、直连虚线、中继点线。后面跟文字 |
| 资源类型 | 小标签的边框线型：文字单实线、图片单虚线、文件双线 |
| 附件块 | 虚线边框的小块，等宽字，如 `[文件 #1]` |
| 传输中 | 连接中的灯加一条进度条 |
| 状态计数 | 30px 等宽数字；为 0 时用 `--muted`；已断开、等你不为 0 时整格用 `--accent` 边框加对应底纹 |

## 4. 色彩 token

组件只引用 token，不写死颜色。新增一套主题就是新增一组取值。

| token | 用途 |
|---|---|
| `--bg` | 底色；也是浮层的底色和反白按钮上的文字颜色，必须是不透明的实色 |
| `--panel` | 卡片、列表行的底 |
| `--raise` | 选中的标签、次级按钮的底 |
| `--line` | 边框、分隔线、暗格、未打开的灯 |
| `--text` | 正文；选中项的边框；主按钮的底 |
| `--muted` | 次要文字；空闲和离线的灯 |
| `--on` | 活动的灯、亮的电平格、进度条 |
| `--accent` | 强调色，只用于已断开和等你，以及它们的动作按钮 |
| `--accent-ink` | 强调色按钮上的文字 |
| `--tint` | 强调色的淡底，用于条纹和等你的行 |
| `--r` | 圆角 |
| `--glow` | 活动灯的光晕 |
| `--font`、`--mono` | 正文字体、等宽字体 |

### 每套主题的质感

| 主题 | 质感 | 额外处理 |
|---|---|---|
| MATRIX | 绿色磷光 CRT 字符终端。全屏只有绿色一个色相，强调色是近白的亮绿 | 全部用等宽字体；全屏叠 1px 扫描线和四角暗角；文字带绿色光晕 |
| AVATAR | 近乎隐形的薄玻璃上浮着发光的蓝青图形，背后是暗一些的实验室 | 底层是几团失焦光斑加淡竖线；面板只有细亮边、顶边一条短高光和一道细反光，轻微模糊；标题字重 400 |
| IRON MAN | 浅蓝青色的全息光 | 全屏叠 32px 的淡蓝网格；文字带蓝色光晕；小标题字距加大 |
| WESTWORLD | 黑底、白色细线和文字、红色点缀 | 小标题字距加大；不加光晕 |

说明：
- MATRIX 的配色有资料可查（模仿单色绿磷光显示器）。AVATAR、IRON MAN、WESTWORLD 的配色是按印象取的，没有找到写明颜色的资料，用户认可"大体风格如此"。
- 主题只取电影的配色和材质感；片名只作为文字标签。不使用片方的图形、标志和字体。
- 主题选择是一个下拉菜单，放在左侧面板底部，顺序是 AVATAR、IRON MAN、MATRIX、WESTWORLD。
- 原型里四套主题的内部代号是 `graphite`（AVATAR）、`holo`（IRON MAN）、`phosphor`（MATRIX）、`bone`（WESTWORLD），是迭代留下的旧名；实现时改成和主题名一致。

## 5. 字体与字号

| 用途 | 字体 | 字号 |
|---|---|---|
| 正文 | Inter，中文回落到 PingFang SC、Hiragino Sans GB、Noto Sans SC、Microsoft YaHei | 15px，行高 1.4 |
| 数字、ID、流量、剪贴板内容、按键 | JetBrains Mono | 12 到 14px |
| 会话名、卡片标题 | 正文字体，字重 600 | 15 到 17px |
| 次要说明 | 正文字体，`--muted` | 12 到 13px |
| 小标题（档位、帧率……） | 正文字体，`--muted`，字距 0.06em | 11px |
| 状态计数 | JetBrains Mono，字重 600 | 30px |

MATRIX 主题下正文也用等宽字体。

## 6. 尺寸与触控

- 所有可点的控件高度不小于 48px。
- 顶栏高 56px。会话条高 60px。设备面板的 app 行高 68px。
- 浮层内边距 10 到 12px，控件间距 6 到 8px。
- 圆角统一用 `--r`。
- 按下反馈：缩到 0.97 倍并提亮。悬停效果只在有鼠标的设备上出现。
- 不依赖悬停、右键、长按才能完成的操作；右键只作为桌面上的等效入口。

## 7. 动效

| 动效 | 参数 | 用在 |
|---|---|---|
| 旋转 | 1.4 秒一圈，匀速 | 连接中的灯、传输中 |
| 闪烁 | 1 秒一次，亮暗各半 | 只有等你的灯 |
| 按下 | 0.08 秒 | 所有按钮 |

系统开了"减少动态效果"时，全部动效关闭。

## 8. 组件约定

| 组件 | 约定 |
|---|---|
| 标签（分组、面板标签、档位……） | 选中：`--text` 边框、`--raise` 底、字重 600；未选中：`--line` 边框、透明底 |
| 主按钮（打开、发送、全部打开） | `--text` 底、`--bg` 字 |
| 次级按钮 | `--line` 边框，`--raise` 或透明底 |
| 强调按钮（重连、已处理） | `--accent` 底、`--accent-ink` 字 |
| 不可撤销的按钮（结束会话、全部结束） | 平时是 `--muted` 字的弱按钮；点一次变成强调按钮并写"再点一次确认"，3 秒后复原 |
| 浮层 | `--bg` 实底、`--text` 边框、深色投影；盖在舞台上，不改变舞台大小 |
| 流量标签 | 电平、数字、下箭头；菜单打开时用选中样式 |
| 嵌入区域的占位 | 1px 虚线边框，居中写窗口标题和一句状态说明 |

## 9. 状态词表

界面上只用这些词，不换说法。

| 对象 | 词 |
|---|---|
| 会话 | 连接中、活动、空闲、已断开、已结束 |
| 会话上的标记 | 等你 |
| 设备 | 在线、离线 |
| App | 未打开 |
| 路径 | 局域网、直连、中继 |
| 动作 | 打开、切到、断开、重连、结束会话、全部打开、全部结束、设为常用、固定、复制到本机 |

"断开"和"结束"不能混用：断开保留条目，结束才消失。

## 10. 无障碍

- 正文和次要文字对所在底色的对比度不低于 4.5:1。
- 状态从不只靠颜色：每盏灯旁边都有文字，或者控件带说明状态的可访问名称。
- 只有图标的按钮都有可访问名称。
- 装饰性的灯、电平、图标对读屏隐藏。
- 全部用真正的按钮、输入框、下拉框，键盘可以走到。
