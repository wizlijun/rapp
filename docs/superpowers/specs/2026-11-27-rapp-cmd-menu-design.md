# 快捷区第一行：命令▾ 与 常用语▾（改正 quick-row 的"按键"）

日期：2026-11-27 · 改正 `2026-11-27-rapp-quick-row-design.md` 的 U5、§6、§6.4、§8 里的"按键动作"

## 为什么改

quick-row 把用户说的"两类快捷键"理解成了「按键 mapping」和「常用语命令」，做出了「按键▾」：⌃R 搜历史、⌃O 展开、⌃B 后台、⌃L 清屏、⌘T 新标签，
外加按键动作编辑页和键盘里的 `k:` 格子。用户的本意是：常用语里的**命令**（/new、/compact 那些）要从常用语里分出来，自成一类。按键动作是之前删掉的东西，
不该回来。

## 用户的决定

1. 按键动作整套去掉：「按键▾」、五个按键动作、它们的编辑页、键盘布局里的 `k:` 格子都没有了。搜历史（⌃R）回到命令里，还是内置命令 `search`，
   id 不变，所以原来的星标和次数接着算（`k:search` → `p:search`）。其余四个直接删。
2. 全局设置里「按键」一行改成「键盘布局」，页面里只有布局编辑和恢复默认布局。

## 现在的样子

- 第一行末尾两个菜单：「命令▾」「常用语▾」。
- 命令▾：常用语 doc 里的全部 `StripCmd`（内置的加用户自己加的，含搜历史），带星；最后一行「设置…」进**命令**页。没认出 AI 工具时整列灰，点了说
  「这里没有认得的 AI 工具，发不了命令」。
- 常用语▾：常用语 doc 里的全部 `Phrase`，带星；「设置…」进**常用语**页。
- 第一行前面：打了星的（命令、常用语都行）按星的顺序；没星时按长期次数，次数相同按列表顺序。和 quick-row 一样。
- 数据还是一个 `phrases` doc（`StripItem` 列表），两个菜单、两个页面按类型分着看。同步、星标、次数照旧；`keys` doc 不再读、不再写、不再同步。
- 设置页：
  - 常用语页：只列常用语；拖动排序、左滑删、点了编辑、＋新增常用语、恢复默认（只换回默认常用语，命令不动）；「显示常用语条」开关留在这里。
  - 命令页（新）：只列命令；拖动排序、左滑删、点了按工具编辑、＋新增命令、恢复默认（只换回内置命令，常用语不动）。
  - 键盘布局页：原来的布局编辑器 + 恢复默认布局 + 同步状态行。
  - 全局设置三行：常用语（N 条）、命令（N 个）、键盘布局。

## 我定的（可改）

- **排序怎么落到一个列表里**：一类里拖动、删、恢复默认，只改这一类占的那些位置，另一类原地不动；新增的放在这一类的最后。两个页面共用一个辅助函数。
- **老的 quick.json（0.15.63/64 写的，里面有 `keys` doc）读进来时一次性迁移**：
  - 常用语 doc 里没有 `StripCmd('search')` 就补一个，放在最后一个命令后面；老按键动作改过名字的，名字带过来；按工具改过的键不带（按键动作的写法和命令的写法对不上，
    这种改动几乎没人做）。
  - 星标 `k:search` → `p:search`；本机次数里的 `k:search` 并进 `p:search`；其余 `k:` 星标和次数丢掉。
  - 改动过的 doc 把 `at` 往前推，好让同步推上去；`keys` doc 下次保存就没了，所以只迁移一次。
- **别的设备还没升级**：它们的次数里可能还有 `k:search`，算总数时当成 `p:search`。它们还可能往中心服务写 `keys` doc，这边不理。中心服务不用改。
- **新装和从 gui.json 迁移**：搜历史留在命令里，不再挪出去。
- 键盘布局里的 `k:` 格子读的时候丢掉（`KeyLayout.cleaned` 只认 `barKeys`）。

## 不做

- 不恢复任何按键动作，也不留"自定义按键"的入口。
- 不改中心服务和协议。
