## 5. 30-minute stability

`scripts/measure-weak.py --profile n1 --path direct --minutes 30` was run as specified: it **cannot connect** (`connect 127.0.0.1:60280: timed out`, same LAN_WAIT cause), so there is nothing to observe on n1. As a stand-in I ran the same 30 minutes on **n3** (the harshest network that does connect; `--profile n3 --path direct --minutes 30`), with a background sampler of `ps` RSS every 30 s (`task18-raw/rss.log`, first sample 30 s after the start).

Result (exit 0): 0 crashed, 0 needed a human, 0 auto-reconnects; 200 characters typed missing 0, extra 0; open 3.54 s; page flip median 5.00 s (n=49, 5 not readable in 30 s; target <= 3 s, so that part is 不过 as on the 10-minute run).
