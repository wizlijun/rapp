# V1b 手机外壳：模拟器验收记录

日期 2026-11-28，分支 `feat/phone-v1b`，HEAD 079be5f9。构建：`scripts/build-ios.sh sim`，安装、启动用 `xcrun simctl`。
截图放在仓库外的 `scratchpad/v1b-shots/`，下面只写文件名。

## 先说结论的限制

- 这台机器的 Xcode 里**没有 Simulator.app**（`open -a Simulator` 报找不到，`mdfind` 也没有；只有 SimulatorTrampoline 和 CoreSimulatorService）。所以只能用 `xcrun simctl` 驱动，没有窗口。
- `simctl` 没有旋转、点按、拖拽、分屏。`cliclick` 也没装。因此下面凡是要点按、旋转、拖分屏的步骤，都**没做成**，标「待用户实机/手动」，不猜结果。
- 模拟器里的 app 没有 hub 接入点和 key（不输入任何真实 key），落在接入页。进不了首页的卡片、面板、设置、会话里面。这些的证据改用 widget 测试，文中分别标「模拟器」和「测试」。

## 步骤 1：iPhone 竖、横；iPad 全屏 → 最窄分屏 → 拖回（验收 2）

**iPhone 竖（模拟器）**
看到了什么：冷启动后约 6 秒的第一张截图，是手机形态的首页：左上 `rapp ▾`，大标题「没有等你的。」，小标题「我的设备」，下面一个「添加设备」框。整体很暗，像淡入没做完或是断开态。约 17 秒后再截，已经变成接入页：标题 rApp，「接入点」「key」两个空输入框，一个「接入」按钮。竖屏下竖着排版，没有溢出，没有 iPad 的顶栏。
截图：`phone-portrait.png`（首页，暗）、`phone-portrait-2.png`（接入页）。

**iPhone 横：待用户实机/手动。** 试过：`simctl help` 查旋转选项（没有）；`open -a Simulator` 想用 AppleScript 点 Device → Rotate Left（Simulator.app 不存在）。测试替代：`gui/test/phone/matrix_test.dart` 里 844×390 三套主题都过（见下面的测试证据）。

**iPad 全屏（模拟器）**
看到了什么：Pad 形态。顶栏有侧栏键、总览键（高亮）、左右箭头、「没有选中的会话」、状态点、全屏键；中间是接入页（rApp、接入点、key、接入）。没有手机外壳。窗口 1640×2360 像素，逻辑短边远大于 600，符合「iPad 全屏是 Pad」。
截图：`ipad-fullscreen.png`。

**iPad 拖到最窄分屏、拖回：待用户实机/手动。** 试过：simctl 没有分屏、拖拽命令；没有 Simulator 窗口、没有 cliclick，没法拖。测试替代：矩阵里 615×1183（iPad 窗口）、600×800、669×951、951×669 是 Pad，599×800 是手机，防抖 250 ms 在每个 boot 里都等过了。

## 步骤 2：三套主题 × 首页、面板、设置、会话里面；灰度（验收 5）

**三套主题实看：待用户实机/手动。** 过不了接入页，也没法点进设置切主题。模拟器里只看到默认主题（暗底绿字）的首页和接入页。

**灰度：待用户实机/手动。** 试过：`xcrun simctl spawn <udid> defaults write com.apple.Accessibility GrayscaleDisplay -bool true`（`defaults read` 回 1），结束并重启 app，再截图 `phone-grayscale-try.png`。截图仍然是绿色。要么这个键对模拟器不生效，要么 `simctl io screenshot` 抓的是滤镜之前的缓冲。无法据此下结论。之后已把这个键删掉。灰度下等你、在干活、做完、断开能不能分清，要在真机上看。

**测试证据（不是模拟器）**：`cd gui && flutter test test/phone/matrix_test.dart`，45 个用例全过。覆盖：
- 手机尺寸 390×844、844×390、375×667、430×932、599×800 加 V1a 量到的 Duo 内外屏；三套主题各一遍；每个尺寸都走首页、面板、设备页、设置页、会话里面，没有异常，没有溢出，可点处检查不低于 56（会话里面的写作版和按键条是 Pad 的同一套控件，高 48/40，测试里单独数出来、不按 56 查，见 final-fix-report）；
- Pad 尺寸 600×800、669×951、951×669、615×1183 出 `MainWindow`，不出手机外壳；
- T9 对比度，三套主题各一条；
- T12 文字放大 2 倍，375×667，三套主题。

灰度分得清靠的是灯的形状（Task 5），没有测试能替代肉眼看，所以仍待实机。

## 步骤 3：中心服务关掉（验收 6）

我没有在模拟器里配置中心服务，按任务说明这就算「关」（假定）。因为也没有 hub key，首页的卡片区看不到，只在第一张截图里瞥到「没有等你的。」加「我的设备 / 添加设备」，没有空格子。这一帧不算验收 6 的证据：没有配置中心服务是我的假定，没有确认过。

实机再看：「设置」里关中心服务，首页还有等你的卡片，没有空格子。

## 步骤 4：待用户实机

### 验收 1：Duo 开合（五分钟操作单）

前提：Duo 上装好本分支的包；A（被控 Mac）在线，会话 X 是 A 上的文本终端，**停在 shell 提示符**（`stty size` 要在提示符下敲，X 里正跑着 Claude Code 之类的程序就看不到），另有会话 Y。

**关于「A 的日志」：A 上没有改尺寸的日志行。** 查过的地方：
- 「日志」页（`gui/lib/log_view.dart`，`Op::Logs`）只收三类：`unreachable`、`refused`、`fault`，没有尺寸一类；
- `rust/term/src/pty/fit.rs` 里 `resize_if_idle` 只往窗口写 `ESC[8;行;列t`，不写日志；`holder.rs`、`view.rs`、`rust/host-core/src` 里也没有带 resize 的日志调用；
- `rust/cli` 里没有对应命令。

所以本单不看日志，改用可观察的东西：**在 A 的会话 X 的终端里输入 `stty size`**，它回「行 列」。把「改没改尺寸」换成「行 列 变没变」。手机上的会话里面请求 `fit: false`（`gui/lib/phone/session_view.dart`），所以合上、展开都不该让这对数字变。注意：展开时「最多改一次」这一条用这个办法看不出来，因为没法区分「没改」和「改了又改回」，单子里只验「行 列 没变」。

操作单（核心部分合计约 4 分 30 秒）：

1. （30 秒）A 上先在会话 X 的终端里输入 `stty size`，记下「行 列」。
2. （30 秒）Duo 展开，打开 X 进「会话里面」，输入框里敲半句话，别发送。
3. （30 秒）让 Y 出一件等你的事（比如 Claude Code 等确认）。
4. （20 秒）合上 Duo。看外屏：应到首页，有「刚才在：X」。
5. （30 秒）展开 Duo。应回到 X 的窗口，半句话还在。
6. （30 秒）在 A 的 X 里再输入 `stty size`，和第 1 步比：行 列 应不变。
7. （30 秒）处理掉 Y 的事，让别的会话都不再等你。在 X 里再敲半句话。
8. （30 秒）再合上。这次应停在 X 的「会话里面」，不是首页。点写作版键：半句话在，能接着打（外屏的会话里面用的是 Pad 的同一个写作版）。
9. （30 秒）展开，半句话还在；A 上再 `stty size`，行 列 应不变。
10. （10 秒）记下：两次合上的落点、「刚才在：X」有没有、草稿在不在、行 列 有没有变。

### Q1：1 秒出卡片（约 1 分钟，和上面合计约 5 分 30 秒）

前提：Wi-Fi，有中心服务，A 上至少有一件等你的事。

1. （10 秒）rapp 放在前台，锁屏。用另一台手机的慢动作录屏对着 Duo。
2. （10 秒）从屏幕点亮（rapp 在前台）开始计时，到首页出卡片为止。要求不超过 1 秒。
3. （30 秒）重复 3 次，记下最慢的一次。
4. （10 秒）再把 rapp 切到后台 10 秒后回来做一次，要求 2 秒内。

## 发现的问题

1. 冷启动：两张截图先是暗的手机首页（「没有等你的。/ 添加设备」），后是接入页。两张之间的时间差是我估的（约 6 秒和约 17 秒），没有确认。若真是先渲染首页再跳接入页，没有 hub 的新用户会先看到一个空首页。Pad（`MainWindow`）用同样的办法挡接入（`_access?.hasKey == false`，读取中为 null），所以这很可能是两边共有的行为，不是手机外壳新增的。需要实机看一遍冷启动。没修。
2. 灰度没抓到，见步骤 2。不算外壳的 bug，是验证手段的限制。

## 结论

模拟器里确认了：
- 构建能过，app 在 iPhone 17e（390×844）上启动成手机形态，在 iPad 全屏上启动成 Pad 形态；
- 新装无 key 时落在接入页，手机和 iPad 都有，没有溢出。

靠测试确认（不是模拟器）：手机五个页面在各尺寸、三套主题下无溢出，可点处不低于 56（会话里面沿用的 Pad 写作版除外），对比度过 T9，文字放大 2 倍可用；Pad 尺寸不出手机外壳；599/600 分界正确。

待用户实机/手动：iPhone 横屏；iPad 最窄分屏来回拖；三套主题实看；灰度实看；中心服务关掉时首页卡片；验收 1（Duo 开合）；Q1（1 秒出卡片）。原因：本机没有 Simulator.app，simctl 不能旋转、点按、拖拽；也没有 hub key 进不了首页。
