# 端口分享

把这台电脑上的一个端口（比如本机的网页、MCP 服务、Redis、sshd）分享给你的别的设备，它们在自己的 `localhost` 上就能用。

## 一个号，到处一样

每个分享有一个**分享号**（28000–28999 里的一个），在你所有的设备上都是同一个。比如你分享了 8007，得到 28000，那么这台、另外两台设备上都用 `http://localhost:28000`。书签、配置文件里的地址不用按设备改。

分享号定下来之后，改备注、改"只给谁"、改协议都不会变。

## 协议和复制

分享时 rapp 会探测这个端口说的是什么，地址按协议写：

| 协议 | 地址 |
| --- | --- |
| http | `http://localhost:28000` |
| https | `https://localhost:28000` |
| tcp | `tcp://localhost:28000` |
| ssh | `ssh -p 28000 localhost` |

探测不出来时按端口猜（22 是 ssh，其他是 http）。猜得不对，用 `--proto` 指定：

```
rapp share 6379 --proto tcp
```

`--proto` 只能是 http、https、tcp、ssh。面板里每一行有地址、协议选择和复制；http、https 才有"打开"。复制出来的就是上表里那一行。UDP 以后再做，现在不支持。

## 号被占了怎么办

- **这台设备上这个号被别的程序占着**（你是访问方）：这台设备会换一个空的号，地址下面写"这台上是 28005（28000 被占）"。占的程序退出后，地址自动换回分享号。
- **分享方这台上的分享号被别的程序占着**：号不变，面板和 `rapp share` 写"本机上 28000 被别的程序占着，本机请用 localhost:8007"，在这台上直接用原端口。
- **两台设备分享的号撞了**：设备 ID 大的那个换号，写"28000 和 Mini 撞了，换成 28003"。别的设备上的地址跟着变，用之前再看一眼。
- 号用完了：写"没有空的号"。

## 长连接

SSE、Streamable HTTP、WebSocket 这类长连接可以用。但设备之间的连线断了，它们也会断；客户端需要自己重连（常见的 MCP 客户端都会）。

## 升级到这个版本后

访问方的地址会变一次（以前每台设备各有各的端口，现在统一成分享号）。书签、MCP 客户端配置里的地址要改一次，以后不再变。

## 命令行

```
rapp share                      看这台设备分享了什么，和每个的地址
rapp share 8007                 分享 8007
rapp share 8007 --proto tcp     分享并指定协议
rapp unshare 8007
rapp hosts                      看别的设备分享了什么，和这台上的地址
```
