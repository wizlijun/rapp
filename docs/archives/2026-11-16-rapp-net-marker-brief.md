# 需求：为桌面远程控制软件设计「全局网络状态」指示标记

日期：2026-11-16。用途：交给创意类 AI 征集视觉方案（不含实现）。

## 背景
这是一个 Flutter 桌面应用（macOS / Windows / Linux），用来远程控制另一台电脑。
窗口顶部有一条 56px 高的顶栏，顶栏右侧有一个常驻的「全局网络状态」标记，表示
**本机到中继服务器这一段网络**的质量。它一直在那里，用户不会主动去看它，但网络一变差
就必须能被余光注意到。

## 要解决的问题
现有标记画的是一条「脉搏线 / 心跳线」：好的时候是一个小波峰，一般是更高的上下跳动，
弱是全程锯齿，断开是一条虚线加一个 ✕。实测观感很怪：四种形状之间没有共同的视觉逻辑，
锯齿像噪声、✕ 像错误图标，用户看不出它们是同一个量的四个刻度，也猜不到哪个更好。
现在要**重新设计这个标记的视觉形式**。

## 必须表达的四档（语义固定，不可增减、不可改名）
| 档 | 含义 | 判定（仅供理解，不必画出数字） |
|---|---|---|
| 强 | 网络很好 | 往返 < 100ms 且丢包 < 2% |
| 一般 | 可用 | 往返 < 300ms 且丢包 < 5% |
| 弱 | 连着但很差 | 达不到「一般」 |
| 断开 | 连不上中继 | 探测连续 3 次无响应，或连接已断 |

四档之间必须有**单调的、一眼能排序的视觉递进**（用户不看说明也能判断哪个更好），
并且四档必须**两两可区分**。

## 硬约束
1. **尺寸极小**：标记总宽 40 逻辑像素（含左右各 6px 内边距），实际可绘制区域约
   **28×14 逻辑像素**。描边宽度 1.5px 左右，需在 1x / 2x 屏都清晰。
   如果方案确实需要更宽，最多可放宽到 96px，但必须说明为什么值得。
2. **没有文字和数字**：具体数值（`中继 160ms · 丢包 3%`）只在鼠标悬停提示和下拉菜单里出现，
   标记本身不能承载文字、数字、百分比。
3. **形状必须能独立区分档位**：颜色只是辅助。原因有两个——需要支持色盲用户；而且本应用
   有「高对比」等多套主题，其中「弱」用的警示色和「断开」用的错误色在某些主题下是**同一个颜色**。
   所以把图去掉颜色变成纯黑白时，四档仍必须能分辨。
4. **不能撞车的已有图形语言**（同一条顶栏或相邻界面里已经在用，必须明显不同）：
   - 手机/wifi 常见的**扇形信号弧**、**阶梯状信号格**：明令禁止，产品不希望被误认成系统网络图标；
   - 紧挨着右边就是**流量速率标记：5 格竖条（亮/暗）**，所以不能用竖条/柱状/格子计数；
   - 会话状态灯已经占用了**实心圆点、圆环、三角、菱形、方块**这五种形状；
   - 不要用常见的告警符号（❗、⚠、✕、红十字）作为某一档的主体。
5. **安静**：这是常驻元素，不能分散注意力。网络正常时必须视觉上"退后"；只有「弱」「断开」
   才允许明显一点。默认静态渲染；如果提动画，必须说明「强/一般」时动画如何几乎不可见，
   并且动画要能在 CPU 开销极低的前提下用 Canvas 自绘实现（无法使用图片资源或 Lottie）。
6. **档位切换不频繁**：变差立即生效，变好要稳定 10 秒才升档，所以不会高频闪动；但相邻两档的
   形状差异要足够大，切换时用户能察觉"它变了"。
7. **实现方式**：Flutter `CustomPainter` 手绘（直线、曲线、圆弧、填充、透明度都可以），
   无法使用字体图标和位图。请用可被直接转成绘制指令的方式描述。

## 交付物（请给 3 个差异明显的方案，不要同一思路的微调）
每个方案包含：
1. 一句话概括这个标记"用什么量的变化"来表示网络好坏（例如密度、完整度、距离……由你定）；
2. 四个档位各自的形状，用 ASCII 草图 + 内联 SVG（视口 28×14）两种方式给出；
3. 配色建议：只说明"用哪一类语义色"（常规文字色 / 警示色 / 错误色 / 强调色），不要给具体色值；
4. 去色（纯黑白）后的四档草图，证明形状本身可分辨；
5. 为什么它不会被看成 wifi 图标、也不会和 5 格竖条混淆；
6. 浅色和深色背景下各自需要注意什么；
7. 一句话说明这个方案的代价或风险。

最后给一个简短对比表，并推荐一个方案。

## 评判标准（按重要性排序）
1. 不看说明就能排出四档的好坏顺序；
2. 28×14 像素内依然清晰，不糊成一团；
3. 去掉颜色仍可分辨；
4. 正常状态足够安静，异常状态足够醒目；
5. 和 wifi 图标、5 格竖条、五种状态灯都不像；
6. 形状本身有统一的内在逻辑，四档像"同一个东西的四个状态"，而不是四个不同的图标。
